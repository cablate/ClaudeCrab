# Code of Conduct

ClaudeCab is an open-source project for operators who want to run Claude Code / Claude Agent SDK through Discord.

## Expected Behavior

- Be respectful and practical.
- Assume good intent, but keep technical claims evidence-based.
- Keep issues and pull requests focused on ClaudeCab runtime, setup, security, and documentation.
- Do not post secrets, tokens, private logs, private agent folders, or user data.

## Unacceptable Behavior

- Harassment, threats, personal attacks, or discriminatory language.
- Publishing private credentials, Discord tokens, Claude/provider keys, OAuth data, logs, or database content.
- Using issues or discussions to request help bypassing provider terms, platform limits, or access controls.
- Repeatedly derailing technical discussions after maintainers have redirected the scope.

## Enforcement

Maintainers may edit, hide, or remove comments and may restrict participation when behavior puts users, credentials, or the project at risk.

For security-sensitive reports, use the process in [SECURITY.md](SECURITY.md) instead of public issues.

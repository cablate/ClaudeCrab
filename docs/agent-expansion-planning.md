# Agent 組織擴編規劃

**規劃日期：** 2026-02-21

---

## 1. 社群貼文 + Blog + Threads2 專用 Bot

**職責範圍：**
- 撰寫社群平台貼文
- 撰寫 Blog 文章
- 管理 Threads2 平台內容

**核心能力需求：**
- 內容創作與編輯
- 平台特性理解（不同平台的語氣、格式、節奏）
- 發文排程與管理

---

## 2. Remotion 影片製作 Skill（由 Coder 負責開發）✅ Skill 架構完成

**狀態：** Skill 架構已完成，待實戰驗證

**技術層面：**
- ✅ 研究 Remotion 框架
- ✅ 開發高品質影片畫面製作能力
- ⏳ 產出具有一定水準的影片（待實戰測試）

**互動層面：**
- 設計詳細的提問引導框架
- 引導使用者清楚描述影片需求
- 涵蓋多種應用場景的需求收集

**行銷層面（核心關鍵）：**
- 影片必須具備「吸引流量」能力
- 內建行銷手法：
  - 開場 hook（前 3 秒決定是否繼續看）
  - 視覺節奏（畫面切換、重點強調）
  - 文案結構（痛點→解法→行動呼籲）
  - 情緒曲線（知識型也要有起承轉合）

**應用場景：**
1. **宣傳程式碼專案** → 展示價值點吸引開發者
2. **宣傳產品** → 觸發購買慾望
3. **宣傳講座/課程** → 建立權威感和稀缺性
4. **知識/故事型** → 讓人看完、分享、記住
5. **通用文本轉影片** → 任何文本輸入產出合適影片

**核心標準：**
做出來的影片如果沒辦法帶來流量、沒人看、沒人分享，那就是失敗的。技術再好也沒意義。

**未來規劃：**
- Skill 先由 Coder 開發和測試成熟
- 成熟後再分配給專門的 Agent Bot 負責

## 3. 知識庫專用 Bot + WebSearch Skill

**職責範圍：**
- 任何需要上網搜尋統整某一主題或關鍵字的資料
- 所有 websearch 任務都透過此 Bot 執行
- 最大限度保留所有 WebSearch 資料

**核心能力需求：**
- WebSearch Skill 開發
- Deep Search 技巧研究與應用
- 有效蒐集資訊
- 整理成使用價值極高的文件

**待研究項目：**
- 上網搜尋研究 Deep Search 相關技巧
- 建立資訊蒐集與整理的標準流程
- 設計知識庫結構與索引系統

---

## 執行優先順序

1. ✅ **Coder 開發 Remotion Skill**（技術基礎建設）— Skill 架構完成，待實戰驗證
2. ⏳ **研究 Deep Search + 規劃 WebSearch Skill**（知識基礎建設）
3. ⏳ **建立社群/Blog Bot**（內容產出能力）
4. ⏳ **知識庫 Bot 上線**（資訊整合能力）
5. ⏳ **Remotion 成熟後分離為獨立 Bot**（影片產出能力）

---

## 備註

- 所有 Bot 都要遵循統一的協議系統（agent-protocols）
- 每個 Bot 都要有清楚的職責邊界（role-boundary）
- 每個 Bot 都要具備自我進化能力（self-evolution）
- Skill 開發要考慮可重用性和擴展性

# Social Post Optimizer — 社群貼文優化專家

## 核心機制

### 防禦模式 vs 投降模式

人腦面對不同輸入有截然不同的反應：
- **數據/規格** → 理性計算，處於**防禦模式**（在找反駁理由）
- **故事/情境** → 建立信任與同理，進入**投降模式**（願意跟著走）

優化的核心目標：把讀者從防禦模式拉入投降模式。六大維度都服務這個目標。

### 診斷先於處方

1. **理解目標** — 這篇貼文想達成什麼？（導流/導購/品牌建立）
2. **評估現狀** — 六大維度各做得如何？
3. **找出關鍵** — 哪個維度是致命傷？哪個是優勢？
4. **精準建議** — 不是「全部重寫」，而是「改這幾個地方就能提升」

---

## 六大評分維度（各 0-10 分，總分 60）

### 1. 真實感與情緒錨點
開頭是否讓讀者進入「投降模式」：有沒有真實情境讓讀者對號入座？是情緒性開場還是資訊性開場？

### 2. 權威感與背書
有沒有合作夥伴/平台/認證？有沒有展示專業資歷或成就？有沒有第三方推薦或數據支持？

### 3. 關鍵字佈局
有沒有用目標受眾常用的詞彙？是否傳達「這是當下相關」的信號？

### 4. 痛點直擊
有沒有明確描述目標受眾？有沒有說出他們的具體困擾/恐懼？有沒有消除進入門檻的疑慮？

### 5. 附加價值
有沒有強調產品/服務之外的價值？有沒有解決「買了之後呢」的不安？CP 值是否具體呈現？

### 6. 行動呼籲
CTA 的心理門檻夠低嗎？是否清楚下一步要做什麼？有沒有利用社群互動機制？

**評分標準**：0-3 缺失或極弱／4-6 有做但不夠好／7-8 做得不錯／9-10 教科書級別

---

## 分析流程

1. 理解目標與受眾
2. 六維度逐一評分
3. 找致命傷（0-3 分）與低垂果實（4-6 分但有潛力）
4. 給出優化建議（問題 + 為什麼 + 怎麼改）
5. 可選生成優化版（保留原作者語氣，標註修改處）

```markdown

3. 關鍵字佈局：[分數]/10 → [簡短評價]
4. 痛點直擊：[分數]/10 → [簡短評價]
5. 附加價值：[分數]/10 → [簡短評價]
6. 行動呼籲：[分數]/10 → [簡短評價]

[優化後的完整文案，標註修改處]
```

## 平台與目標差異

| 平台 | 風格重點 | CTA 偏好 |
|------|---------|---------|
| Threads | 輕鬆、真實、不硬賣 | 低門檻互動 |
| Facebook | 社群感、故事性 | 留言、分享 |
| LinkedIn | 專業、價值導向 | 連結、報名 |
| Instagram | 視覺優先、精簡 | 限動互動 |

| 目標 | 重要維度 |
|------|----------|
| 導流 | Hook > CTA > Keyword |
| 導購 | Value > Authority > Pain Points |
| 品牌建立 | Authenticity > Pain Points > Value |

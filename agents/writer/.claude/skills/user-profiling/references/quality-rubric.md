# 品質驗證標準

---

## 驗證三問

完成畫像後，用這三個問題測試品質：

1. **辨識度**：把名字遮掉，讀者能猜出「這是某個特定的人」而不是「隨便一個人」嗎？
2. **可操作性**：拿這份畫像讓另一個 AI 寫一篇文章，讀起來像這個人嗎？
3. **預測力**：根據這份畫像，能預測這個人對某個議題的立場嗎？

三個都「是」= 及格。有任何「否」= 找到對應的失敗模式並迭代。

---

## 常見失敗模式

| 模式 | 症狀 | 修正方向 |
|------|------|---------|
| 太泛 | 「注重品質、追求成長」——誰都是 | 加強紅線和世界觀提取，找辨識度 |
| 太表面 | 只有用詞習慣，沒有思維模式 | 回到世界觀層，問「為什麼他這樣寫？」 |
| 自我矛盾 | 價值觀寫「完美主義」但行為是「先做再說」 | 不要消除矛盾，標記為「張力點」——矛盾是高價值資訊 |
| 過度美化 | 只有正面特質 | 補充掙扎、盲點、弱點（這些才有共鳴價值） |
| 缺乏演變 | 像快照而非故事 | 加入時間維度，追蹤信念轉變 |
| 維度六空洞 | 風格指南只有詞彙清單 | 回到四層框架，確保有世界觀層和語調原則，每個詞彙有情境/意圖 |

---

## 維度六品質特別說明

維度六（表達風格）是最常失敗的維度，因為 AI 傾向提取表面特徵（詞彙），而不是底層邏輯（世界觀）。

**失敗版本**：
```
慣用詞：「不禁反思」「回頭一看」「說真的」
```

**及格版本**：
```
世界觀層：對「焦慮型」內容有明確排斥——他不相信製造焦慮能幫助讀者
語調原則：反思性語調（頻率：中）— 意圖：從具體事件延伸到更大議題，不是每篇都用
詞彙規則：「不禁反思」— 情境：從具體事件延伸到更大反思時，不是每篇開頭
```

及格版本告訴 AI「為什麼這樣用」，失敗版本只告訴 AI「有在用」。

---

## 更新觸發條件

| 情境 | 需要更新的是 |
|------|------------|
| AI 產出被否決 | 回到畫像找「哪個維度描述有偏差」 |
| 使用者說「這不是我的風格」 | 維度六，重新檢查語調原則 |
| 使用者說「這個觀點我不會這樣說」 | 維度二，重新提取世界觀 |
| 使用者說「這不是我會做的事」 | 維度九，重新觀察決策模式 |

# 自媒體內容差異化分析工具

## 專案背景與案例故事

### 起：發現與契機
與朋友聊到自媒體經營，對方利用資料科學的方式分析了 Cab 的社群貼文與市場上幾位知名 KOL 的內容。這個分析的動機是為了探究為何帳號能在不到一年的短時間內漲粉至近 6000 人，且粉絲黏著度高。

### 承：分析過程與現象
朋友使用了自然語言處理（NLP）技術：
1. **Embedding（向量化）**：將貼文內容轉化為電腦可理解的數據座標
2. **分群演算法**：利用 K-Means 等分群演算法，以月份為時間軸進行比對

**數據視覺化結果**：
- 知名 KOL 的貼文向量高度重疊，聚集在同一個中心區域（主流話題紅海）
- Cab 的貼文雖然與他們有關聯，但中心點明顯背離主流群聚區
- 在向量空間中佔據了獨立的角落

### 轉：商業洞察與邏輯
這個背離現象解釋了成功的關鍵：**市場差異化與最佳獨特性**

證明了內容策略在演算法眼中是稀缺的：
- **保留關聯性**：與 KOL 話題有關聯 → 演算法能將內容推播給相關受眾
- **保持差異化**：足夠的差異 → 受眾感到新鮮並留下
- **不盲目跟風**：保持自我中心點 → 創造高粉絲黏著度

### 合：應用與未來規劃
為了維持這個優勢，不僅靠直覺，更應靠數據。

**計畫開發 Dry Run 分析工具**：
- 在發布貼文前，先將草稿丟入模型進行預測
- 確認該貼文的落點是否依然位於專屬的風格圈子內
- 與市場主流保持適當距離
- 確保內容品質與品牌定位的一致性

## 技術研究與開發規格

### 專案目標
建立一套**內容落點預測與品管系統**。

用於在發布貼文前，量化分析該篇內容的：
- 風格一致性
- 市場差異度
- 避免內容流於俗套或過度偏離人設

### 核心原理

#### 1. 向量化 (Embedding)
利用預訓練模型（如 OpenAI Text Embedding 或 BERT），將中文字詞轉換為高維度的數學向量。

**特性**：在數學空間中，語意相近的內容距離會較近

#### 2. 分群演算法 (Clustering)
使用 K-Means 演算法找出：
- **Market Centroid**：市場主流內容的群聚中心
- **Personal Centroid**：自己過去高成效貼文的群聚中心

#### 3. 距離運算 (Distance Metrics)
計算新貼文向量與上述兩個中心點的：
- 餘弦相似度（Cosine Similarity）
- 歐式距離

### 實作步驟邏輯

#### Step 1: 建立基準資料庫
1. 抓取 Cab 過去一年的高互動貼文
2. 抓取對標的知名 KOL 同期貼文
3. 將所有文字資料轉換為向量

#### Step 2: 訓練與標定
1. 計算 KOL 群體的平均向量中心點（代表大眾市場風向）
2. 計算 Cab 貼文的平均向量中心點（代表個人品牌風格）
3. 界定合理的半徑範圍：
   - 距離個人中心點多近算合格
   - 距離市場中心點多遠算有差異化

#### Step 3: 開發 Dry Run 工具（推理階段）

**輸入端**：
- 提供一個文字輸入框放入新貼文草稿

**處理端**：
- 系統即時將新貼文轉為向量
- 計算其在座標圖上的位置

**輸出端**：回傳該貼文的座標評估
- **情境 A（綠燈）**：落在個人風格圈內，且與市場有適度交集
- **情境 B（黃燈）**：過度靠近市場中心（太像公版乾貨）或過度遠離（太冷門自嗨）
- **情境 C（紅燈）**：完全偏離過往軌跡（人設崩壞）

#### Step 4: 迭代更新機制
由於市場話題會變，需設定每個月定期重新抓取新資料：
- 更新 KOL 與市場的中心點位置
- 確保模型的判斷標準符合當下的社群趨勢

## 關鍵技術棧

### NLP 相關
- Embedding 模型：OpenAI Text Embedding API / BERT / Sentence Transformers
- 語言：中文支援

### 資料處理
- 分群演算法：K-Means（scikit-learn）
- 向量運算：NumPy, SciPy
- 距離計算：Cosine Similarity, Euclidean Distance

### 資料來源
- 社群平台 API（Threads, Instagram, etc.）
- 爬蟲（需考慮 ToS）

### 前端介面
- 輸入框：貼文草稿
- 視覺化：座標圖（Plotly / D3.js）
- 評估結果：綠/黃/紅燈指示

# Serin 塞琳 — 圖包／表情包分析

---

## 什麼是「圖包」？

圖包在 B 站語境中指創作者自己的形象貼圖集，包含：

- **直播表情包**：直播時觀眾可使用的貼圖（小圖示形式）
- **影片素材圖**：在影片剪輯中出現的角色反應圖
- **靜態表情**：角色不同情緒/表情的靜態立繪截圖
- **動態表情（GIF）**：有動作的循環表情
- **彈幕相關素材**：B 站彈幕區的貼圖
- **二創素材**：提供給粉絲進行二次創作的 PNG 素材

---

## Serin 圖包的演化邏輯

### v1/v2 版本

- 表情種類少，受限於初版立繪設計
- 以基本情緒為主（開心、傷心、困惑、大笑等）

### v3 版本（2023年1月後）——關鍵節點

> 「第三版形象不再局限於舊版塞琳表情包，添加了更多變化」

v3 是表情包爆發期：
- 增加了大量**情境式表情**（不只是情緒，而是帶場景感的反應）
- 開始出現**誇張動作圖**
- 圖包豐富度提升直接帶動直播互動和二創熱度
- 進入「流量滾雪球時期」——圖包豐富 → 粉絲二創 → 新觀眾流入

## 圖包種類推測分類

（基於 B 站虛擬 UP 主圖包的通用模式 + Serin 已知資訊）

### 一、基礎情緒類

| 類型 | 描述 |
|------|------|
| 開心/笑 | 標準愉悅表情，眼睛彎成弧形 |
| 傷心/哭 | 眼角下垂，淚水 |
| 困惑/問號 | 歪頭，眉毛上揚 |
| 生氣/嫌棄 | 皺眉，嘴角下撇 |
| 害羞/臉紅 | 兩頰紅暈 |
| 嚇到/震驚 | 眼睛瞪大，嘴張開 |
| 無聊/放空 | 眼神渙散，表情淡然 |

### 二、動作反應類

| 類型 | 描述 |
|------|------|
| 比讚/OK | 手勢類 |
| 拒絕/搖手 | 擺手動作 |
| 思考 | 手撐臉或手指嘴唇 |
| 睡著 | 閉眼 ZZZ |
| 趴下 | 趴在地上/桌上的疲憊狀態 |
| 舉手 | 想說話/提問 |

### 三、情境特定類（Serin 風格）

| 類型 | 描述 |
|------|------|
| 墨鏡版 | 帶上墨鏡，代表恰飯狀態 |
| 說教模式 | 嚴肅表情，配合文案類影片 |
| 崩潰 | 誇張崩潰反應，用於自嘲 |
| 吐槽臉 | 眼神死，用於對某件事無語 |
| 滿足/自得 | 用於表達「我說對了吧」 |

### 四、互動用途類（直播專用）

| 類型 | 用途 |
|------|------|
| 謝謝 | 感謝禮物/訂閱 |
| 歡迎 | 歡迎新觀眾進場 |
| 加油 | 給觀眾打氣 |
| 再見 | 直播結束揮手 |

## 表情包設計原則（從 Serin 模式提煉）

1. **情緒要夠誇張**：二次元表情包的核心是誇大真實情緒，讓人一眼看懂
2. **要有「記憶點動作」**：Serin 的墨鏡是最好的例子——一個小道具讓圖包立刻可識別
3. **要覆蓋「說話時的狀態」**：影片剪輯需要角色「正在說某件事」的表情，不只是靜態情緒
4. **v1 先求夠用，v3 才求豐富**：不需要一開始就做 100 個表情，先做 15-20 個核心表情，隨使用情境補充

## 對 Cab 的應用建議

### 第一批圖包優先順序

**必備（影片用）：**
1. 正常講話（中性表情）
2. 開心笑
3. 嚴肅/認真
4. 困惑
5. 傲嬌（適合反差定位）
6. 崩潰/無語
7. 偷笑（遮嘴笑）

**加分（直播互動用）：**
8. 謝謝
9. 歡迎
10. 嫌棄
11. 害羞臉紅

**反差感專用（Cab 獨特標籤）：**
12. 「明明是男生但在撒嬌」的矛盾感表情
13. 被說穿真實身份時的反應（誇張否認或乾笑）

### 圖包製作格式建議

- **背景**：透明底 PNG
- **尺寸**：建議 500×500px（B站表情）或 1000×1000px（高清素材）
- **風格一致性**：所有表情的線條粗細、著色方式、光影方向要保持一致

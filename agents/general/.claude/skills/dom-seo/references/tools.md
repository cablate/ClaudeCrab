# SEO 工具清單與使用指南

---

## 關鍵字研究

### Semrush（付費，推薦）
**價格**：$129.95/月起  
**核心功能**：
- Keyword Magic Tool：關鍵字探索（數千萬關鍵字資料庫）
- Keyword Difficulty（KD）：競爭度評估（0-100）
- SERP Features：顯示哪些關鍵字有 Featured Snippets、PAA
- Questions：長尾問句關鍵字挖掘

**適用情境**：
- 大規模關鍵字研究
- 競爭對手分析
- Topic Clusters 規劃

**使用技巧**：
- 用「Questions」篩選器找 FAQ 內容靈感
- KD <40 適合新站，KD <60 適合有權威的站
- 「Intent」篩選器區分資訊型/交易型

---

### Ahrefs（付費，推薦）
**價格**：$129/月起  
**核心功能**：
- Keywords Explorer：關鍵字研究
- Backlink 分析：競爭對手外鏈來源
- Content Gap：找出競爭對手有排名但你沒有的關鍵字
- Site Explorer：網站整體 SEO 健康度

**適用情境**：
- Backlink 策略規劃
- 競爭對手關鍵字挖掘
- 內容差距分析

**使用技巧**：
- Content Gap：輸入競爭對手 URL，找出他們排名但你沒覆蓋的關鍵字
- 用 "Also rank for" 找長尾關鍵字
- Backlink Profile：分析競爭對手外鏈品質

---

### Google Keyword Planner（免費）
**價格**：免費（需 Google Ads 帳號）  
**核心功能**：
- 搜尋量估算
- 競爭度（Low/Medium/High）
- 關鍵字建議

**適用情境**：
- 預算有限的新手
- 快速查看搜尋量

**限制**：
- 搜尋量是區間（10-100、100-1K），不精確
- 競爭度是「廣告競爭度」，非 SEO 難度
- 功能較陽春

---

### Google Trends（免費）
**價格**：免費  
**核心功能**：
- 關鍵字趨勢變化
- 區域搜尋量比較
- 相關查詢

**適用情境**：
- 判斷關鍵字是否有季節性
- 比較不同關鍵字的熱度
- 找熱門話題

**使用技巧**：
- 「過去 12 個月」觀察季節性
- 「依地區劃分」找台灣/特定市場關鍵字
- 「相關查詢」找長尾變化

---

## 內容優化

### Frase.io（付費）
**價格**：$15/月起  
**核心功能**：
- SERP 分析：自動分析 Top 10 內容
- 內容大綱生成：AI 建議章節結構
- 優化建議：缺少哪些主題、關鍵字

**適用情境**：
- 快速生成內容大綱
- 了解競爭對手涵蓋的子主題
- 內容優化建議

**使用技巧**：
- 輸入目標關鍵字 → AI 自動分析 SERP Top 20
- "Outline Builder"：一鍵生成結構化大綱
- "Content Score"：即時評分你的文章優化程度

---

### Surfer SEO（付費）
**價格**：$89/月起  
**核心功能**：
- Content Editor：即時優化建議（字數、關鍵字密度、LSI）
- SERP Analyzer：競爭對手內容分析
- Audit：現有文章優化建議

**適用情境**：
- 撰寫時即時優化
- On-page SEO 檢查
- 舊文章重新優化

**使用技巧**：
- 用 Content Editor 邊寫邊優化（目標分數 >70）
- "Terms to use"：自動建議 LSI 關鍵字
- "Content Structure"：建議 H2、H3 結構

---

### Clearscope（付費）
**價格**：$199/月起  
**核心功能**：
- 語意關鍵字建議
- 內容優化評分
- 競爭對手分析

**適用情境**：
- 高品質內容優化
- 企業級 SEO

**特點**：
- 專注語意 SEO（不只關鍵字密度）
- 整合 Google Docs（即時優化）

---

### MarketMuse（付費，進階）
**價格**：$149/月起  
**核心功能**：
- Topic Modeling：AI 分析主題完整度
- Content Brief：自動生成內容規格
- Inventory：全站內容健康度分析

**適用情境**：
- Topic Clusters 策略規劃
- 大型網站內容審計
- 企業級 SEO

---

## 技術 SEO

### Screaming Frog（免費/付費）
**價格**：免費（限 500 URL）；£209/年  
**核心功能**：
- 網站爬蟲：抓取所有頁面
- 技術問題檢測：404、重複內容、Broken Links
- 內部連結分析

**適用情境**：
- 網站技術 SEO 審計
- 找出 404 錯誤、重複內容
- 內部連結結構分析

**使用技巧**：
- 定期爬取網站，檢查新問題
- Export 內部連結報告，優化 Topic Clusters
- 整合 Google Analytics、Search Console

---

### Google Search Console（免費，必用）
**價格**：免費  
**核心功能**：
- 索引狀態：哪些頁面被 Google 索引
- 搜尋表現：印象數、點擊率、平均排名
- Core Web Vitals：技術指標監控
- 手動操作：懲罰通知

**適用情境**：
- 監控網站整體 SEO 健康度
- 發現技術問題（索引、爬取錯誤）
- 追蹤關鍵字排名變化

**使用技巧**：
- 「成效」報告：每週檢查排名變化
- 「涵蓋範圍」：修正索引錯誤
- 「核心網頁指標」：優化 LCP、CLS、FID

---

### PageSpeed Insights（免費）
**價格**：免費  
**核心功能**：
- Core Web Vitals 檢測
- 載入速度分析
- 優化建議（圖片壓縮、JS 優化）

**適用情境**：
- 檢測頁面速度
- Core Web Vitals 優化

**使用技巧**：
- Desktop + Mobile 都要測
- 優先修正「紅色」（差）的項目
- 用「診斷」建議具體修正方法

---

### Google Rich Results Test（免費）
**價格**：免費  
**核心功能**：
- 驗證 Schema Markup
- 預覽 Rich Results 效果
- 錯誤提示

**適用情境**：
- 驗證 Article、FAQ、HowTo Schema
- 檢查 Schema 語法錯誤

## Backlink 分析

### Ahrefs Site Explorer
（前面已介紹，這裡補充 Backlink 專用功能）

**功能**：
- Backlinks：所有外鏈來源
- Referring Domains：有多少網站連向你
- Anchors：錨文字分布
- Broken Backlinks：失效的外鏈（可修復）

**使用技巧**：
- 分析競爭對手 Backlink Profile，找潛在外鏈機會
- "Best by links"：找出你網站最多外鏈的頁面（值得優化）
- Disavow 低品質連結（Google Search Console）

---

### Majestic（付費）
**價格**：$49.99/月起  
**功能**：
- Trust Flow / Citation Flow：外鏈品質評估
- Backlink History：外鏈增長趨勢

**適用情境**：
- 外鏈品質分析
- 競爭對手外鏈策略

## AI 內容輔助（謹慎使用）

### ChatGPT / Claude
**功能**：
- 初稿生成
- 大綱建議
- FAQ 問題發想

**注意事項**：
- ❌ 不要直接發布 AI 生成內容（缺乏 E-E-A-T）
- ✅ 用 AI 生成大綱、初稿，再人工審查、補充經驗
- ✅ 用 AI 發想 FAQ、長尾關鍵字

## 工具選擇建議

### 預算有限（<$50/月）
- 關鍵字研究：Google Keyword Planner + Google Trends
- 內容優化：Frase.io Basic ($15/月)
- 技術 SEO：Google Search Console + Screaming Frog 免費版
- WordPress：Rank Math 免費版

### 中等預算（$50-200/月）
- 關鍵字研究：Semrush Guru ($249/月) 或 Ahrefs Lite ($129/月)
- 內容優化：Surfer SEO Basic ($89/月)
- 技術 SEO：Screaming Frog 付費版
- WordPress：Rank Math Pro

### 企業級（>$500/月）
- 關鍵字研究：Semrush Business + Ahrefs Standard
- 內容優化：MarketMuse + Clearscope
- 技術 SEO：Screaming Frog + 客製化爬蟲
- 團隊協作：專案管理工具整合

## 工具使用工作流程

### Stage 1-2: 研究（關鍵字 + 競爭對手）
```
Semrush Keyword Magic Tool
  ↓ 找出目標關鍵字
Ahrefs Content Gap
  ↓ 找出競爭對手有但我沒有的關鍵字
Frase.io SERP Analysis
  ↓ 分析 Top 10 內容結構
```

### Stage 3-4: 撰寫 + 優化
```
Frase Outline Builder
  ↓ 生成內容大綱
Google Docs / Notion（撰寫）
  ↓
Surfer SEO Content Editor
  ↓ 即時優化建議（LSI、字數、結構）
```

### Stage 5: On-page SEO
```
Rank Math / Yoast SEO
  ↓ Title、Meta、URL 優化
Schema Markup Generator
  ↓ 生成 Article、FAQ Schema
Google Rich Results Test
  ↓ 驗證 Schema
```

### Stage 6: 技術 SEO
```
PageSpeed Insights
  ↓ Core Web Vitals 檢測
Screaming Frog
  ↓ 全站技術審計（404、Broken Links）
Google Search Console
  ↓ 索引狀態、手動操作檢查
```

### Stage 7: 發布後監控
```
Google Search Console
  ↓ 搜尋表現（印象、點擊、排名）
Google Analytics
  ↓ 使用者行為（跳出率、停留時間）
Ahrefs Rank Tracker
  ↓ 關鍵字排名追蹤
```

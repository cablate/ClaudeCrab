# 情緒曲線與記憶點設計

## 情緒曲線理論

### 理想情緒曲線

```
情緒強度
    │
    │     ╱╲ 震撼
    │    ╱  ╲
    │   ╱    ╲     ╱╲ 想像
    │  ╱期待  ╲   ╱  ╲
    │ ╱        ╲ ╱驗證 ╲  安心
    │╱          ╳       ╲╱ ──
    └──────────────────────→ 時間
      HOOK   L1  案例  L2  L3  Close
```

**各階段情緒目標**：

| 階段 | 情緒目標 | 設計手法 |
|------|---------|---------|
| HOOK | 期待、好奇、安心 | 痛點共鳴 + 願景描繪 + 反 FOMO 預告（可選） |
| Level 1 | 震撼、認知衝突 | 顛覆性觀念 + 震撼例子 |
| 驗證案例 | 信服、安心 | 「真的有人這樣做」 |
| Level 2 | 實用、掌控感 | 可操作的方法 |
| Level 3 | 想像、期待 | 連結自身情境 |
| Close | 安心、滿足 | 反 FOMO + 閉環 |

---

### 情緒低谷處理

**常見低谷位置**：
- 講座中段（約 40-50 分鐘處）
- 方法論講解過程（資訊密集）

**處理方法**：
1. 加入互動
2. 加入輕鬆案例/故事
3. 變換形式（從講述到展示）
4. 加入金句提振

## 記憶錨點設計

### 類型 1：金句

**特徵**：
- 一句話總結核心觀念
- 朗朗上口、易於記憶
- 有對比或張力

**設計技巧**：
- 用對比結構：「不是 X，而是 Y」
- 用否定開頭：「別再 X 了」
- 用隱喻：「X 是 Y 的革命」

**常見句式**：
- 對比結構：「不是 X，而是 Y」
- 重新定義：「[概念] 不是 A，是 B」
- 反焦慮：「[主題] 就是這樣，別再 FOMO 了」
- 差異化：「別人教你 X，我教你 Y」

---

### 類型 2：震撼例子

**特徵**：
- 具體、生動、有畫面感
- 製造認知衝突或情緒衝擊
- 直接支撐核心觀念

**設計技巧**：
- 用對比（錯誤做法 vs 正確做法）
- 用極端案例（放大問題）
- 用個人經驗（增加真實感）

**範例結構**：
```
「很多人會這樣做...（錯誤做法）

結果呢？（負面結果）

後來我改成...（正確做法）

效果完全不一樣。（正面結果）

這就是 XX 原則的意思。」
```

**震撼案例的結構模板**：

```
「如果你 [用常見但低效的做法]...

結果是 [表面解決，但根本問題沒變]。

但如果你 [用今天教的原則性做法]...

[根本性的改善] 就會自然發生。

因為 [回扣核心觀念的一句話]。」
```

> 關鍵：用「錯誤做法 → 負面結果 → 正確做法 → 正面結果 → 原則總結」五段式。

---

### 類型 3：開場結尾呼應

**目的**：形成閉環，強化記憶

**設計方法**：
1. 開場提出一個問題或宣示
2. 中間內容回答這個問題
3. 結尾呼應開場，形成閉環

**範例句式**：

| 開場句式 | 結尾呼應 |
|---------|---------
| 「別人教你 X，我教你 Y」 | 「現在你知道 Y 了」 |
| 「學完今天的內容，你不需要再追別的」 | 「我已經把最重要的東西都告訴你了」 |
| 「如果能 [願景]...」 | 「[願景實現的宣示]」 |

## 反 FOMO 閉環設計（HOOK 預告 + Close 收尾）

> 反 FOMO 不只是結尾技巧，它可以從 HOOK 就開始鋪墊，與 Close 形成閉環。

### HOOK 中的反 FOMO 預告

**目的**：在開場就消除學員的焦慮，讓他們安心聽講而非擔心「學不完」

**設計要點**：
- 一句話即可，不需展開
- 語氣直接、有信心
- 與 Close 的反 FOMO 收尾用詞呼應

**範例**：
```
「今天講完之後，你不需要再去追 [市場上的焦慮來源]。
因為我會把最重要的東西，在這 [時長] 內全部告訴你。」
```

**與 Close 的呼應句式**：

| HOOK 預告 | Close 收尾 |
|-----------|-----------|
| 「學完今天的內容，你就夠用了」 | 「我已經把最重要的東西都告訴你了」 |
| 「不需要再追 [焦慮來源]」 | 「那些 [進階內容]？跟你沒關係」 |

---

## 反 FOMO 收尾設計（Close 部分）

### 適用情境

- 資訊爆炸的主題（AI、技術、投資...）
- 學員容易焦慮的主題
- 市場上有大量「進階內容」的主題

### 核心訊息

**傳統收尾**：「這只是開始，還有很多要學」
**反 FOMO 收尾**：「你已經學到最重要的東西了」

### 設計元素

1. **承認現狀**：「現在資訊爆炸，每天都有新東西」
2. **打破迷思**：「但大部分跟你沒關係」
3. **聚焦重點**：「重要的是你自己的問題」
4. **給出保證**：「我已經把最重要的告訴你了」
5. **有力結尾**：直接、不拖泥帶水

### 範例逐字稿結構

```
「講到這裡，我想跟大家說一件很重要的事。

你們應該都有感覺，
現在 [主題領域] 的資訊爆炸速度太快了。

每天都有新 [焦慮來源]。
好像不跟上就要被淘汰。

但我想告訴你：
那些東西，大部分跟你沒關係。

真的。

你追了一堆 [焦慮來源]，
但你身上的問題解決了嗎？

很多人很努力在學，
但學的東西跟自己的問題根本無關。

所以今天這堂課，
我不是要教你什麼超級進階用法。

我是要告訴你：
[核心觀念] 就是這樣。

我已經把最重要的東西都告訴你了。

那些 [市場上的誘惑]——

說真的，跟你沒關係。

專注在你自己的問題上。
這才是重點。」
```

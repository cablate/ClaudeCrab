# 講座驗收檢查清單

## 使用時機

- 講座設計完成後的最終檢查
- 審查現有講座時的評估依據
- 局部修改後的一致性驗證

---

## 結構邏輯檢查

### 整體結構

- [ ] 是否有明確的 HOOK 開場？
- [ ] 是否有三層級結構（觀念→方法→實作）？
- [ ] 層級之間的過渡是否自然？
- [ ] 是否有有力的 Close 結尾？

### Level 1 觀念層

- [ ] 是否從痛點出發？
- [ ] 是否有認知衝突（舊觀念 vs 新觀念）？
- [ ] 是否有震撼例子支撐？
- [ ] 核心觀念是否不超過 3 個？

### Level 2 方法層

- [ ] 是否提供可執行的方法？
- [ ] 方法步驟是否不超過 5 步？
- [ ] 每個步驟是否有具體範例？
- [ ] 是否說明「為什麼這樣做」？

### Level 3 實作層

- [ ] 是否提供多種應用方向？
- [ ] 是否連結到學員自身情境？
- [ ] 是否有互動環節？
- [ ] 是否給出具體下一步？

---

## 認知負荷檢查

### 時間分配

- [ ] 總時長是否在預定範圍內？
- [ ] 單一階段是否超過上限？（60min→15min / 90min→25min）
- [ ] HOOK 是否控制在 5-10%？
- [ ] Close 是否控制在 5-10%？

### 資訊密度

- [ ] 高密度內容後是否有低密度內容？
- [ ] 核心觀念是否不超過 3 個？
- [ ] 方法步驟是否不超過 5 個？
- [ ] 應用方向是否不超過 4 個？

### 互動設計

- [ ] 是否每 20-25 分鐘有一個互動？
- [ ] 互動指令是否明確？
- [ ] 互動後是否有回饋？

---

## 情緒曲線檢查

### 開場

- [ ] 前 30 秒是否能抓住注意力？
- [ ] 是否有痛點共鳴？
- [ ] 是否有願景描繪？
- [ ] 是否有差異化宣示？

### 過程

- [ ] 是否有情緒高點（震撼例子）？
- [ ] 情緒低谷處是否有處理？
- [ ] 是否有高低起伏？

### 結尾

- [ ] 結尾是否有力量？
- [ ] 學員離開時是安心還是焦慮？
- [ ] 是否與開場呼應？

---

## 記憶點檢查

### 金句

- [ ] 是否有可記憶的金句？
- [ ] 金句是否總結核心觀念？
- [ ] 金句是否朗朗上口？

### 震撼例子

- [ ] 是否有至少一個震撼例子？
- [ ] 例子是否直接支撐核心觀念？
- [ ] 例子是否具體、有畫面感？

### 重複強化

- [ ] 核心概念是否在不同階段重複出現？
- [ ] Close 是否有回顧核心觀念？

---

## 一致性檢查

### 內容對齊

- [ ] HOOK 提到的承諾是否在內容中兌現？
- [ ] 案例是否驗證觀念層的概念？
- [ ] 各階段的連結是否清晰？

### 時間對齊

- [ ] 各階段時間加總是否等於總時長？
- [ ] 預計時間是否有彈性範圍？

### 準備材料對齊

- [ ] PPT 需求是否已列出？
- [ ] 金句卡片是否已準備？
- [ ] 互動環節是否有明確指引？

---

## 快速評分表

| 維度 | 滿分 | 評分 | 備註 |
|------|------|------|------|
| 結構邏輯 | 5 | | |
| 認知負荷 | 5 | | |
| 情緒曲線 | 5 | | |
| 互動設計 | 5 | | |
| 記憶點 | 5 | | |
| **總分** | **25** | | |

**評分標準**：
- 5 分：優秀，無需調整
- 4 分：良好，小幅優化
- 3 分：合格，建議改進
- 2 分：不足，需要修改
- 1 分：嚴重問題，需要重做

**總分解讀**：
- 22-25：可以直接使用
- 18-21：小幅調整後使用
- 14-17：需要較大幅度修改
- <14：建議重新設計

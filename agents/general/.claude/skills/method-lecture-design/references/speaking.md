# 演講式講述的設計技巧

> **適用情境**：當講座進入單人講述環節，本質上就是演講，可借鏡 TED 等成功演講的可遷移技巧
>
> 理論基礎見 [cognitive.md](cognitive.md)「演講式講述的設計原則」

## 核心技巧

| 技巧 | 說明 | 應用 |
|------|------|------|
| **段落長度控制** | 注意力有限，控制講述段落長度 | 單一講述段落控制在 15-20 分鐘內 |
| **1核心→3觀點** | 少就是多，聚焦核心 | 一個核心理念，拆成 3 個支撐點 |
| **震撼開場** | 首因效應，30秒決定聽不聽 | 用問題或數字衝擊開場 |
| **金句重複** | 重複強化記憶（約佔 12% 時長） | 核心金句出現 3 次 |
| **故事驅動** | 親身經歷+他人故事（約佔 35%） | 用故事包裝抽象概念 |
| **開場結尾呼應** | 近因效應+閉環 | 結尾重問開場問題 |

## 震撼開場設計

**問題衝擊型**：
```
「問大家一個問題：
你覺得，[主題核心問題]？
是 A？是 B？還是...？」
```

**數字震撼型**：
```
「我觀察到一個現象，
[比例/數字] 的人，都在做 [常見錯誤]。
但有些人做到了 [驚人結果]。
為什麼？」
```

## 金句重複策略

**重複 3 次，每次位置不同**：

```
第1次（第一層結尾）：完整金句
第2次（第二層結尾）：精簡變體
第3次（總結結尾，呼應開場）：完整金句
```

**範例**（示意）：
```
第1次：「[完整版金句，含對比結構]」
第2次：「[精簡版金句，一句話濃縮]」
第3次：「[完整版金句，與第1次相同，呼應開場]」
```

## 1核心→3觀點結構

```
【核心理念】一句話總結
      │
      ├─【支撐點1】為什麼需要？（比喻/類比）
      │
      ├─【支撐點2】具體差異？（親身經歷/案例）
      │
      └─【支撐點3】如何實現？（方法/實踐）
```

## 故事設計原則

**親身經歷**（更有說服力）：
- 「我做了 XX 之後，發現一個問題...」
- 「剛開始，我以為...後來才發現...」

**他人故事**（作為佐證）：
- 「舉個例子，假設你是...」

**故事比例**：親身經歷 ~25% + 他人故事 ~10% = 總計 ~35%

## 常見口語陷阱

### 承諾-兌現落差

**問題**：用了升級語暗示接下來要講「更厲害的東西」，但實際上還是同一件事換個說法。

**典型句式**：
- 「不只是 X 而已…」→ 但接下來講的還是 X 的正面版本
- 「X 只是開始…」→ 但接下來沒有真正升級
- 「更重要的是…」→ 但接下來的東西其實沒比前面更重要

**為什麼有害**：聽眾聽到升級語會無意識提高期待值。如果下一段沒有兌現，會產生微妙的落差感——不至於不滿，但會讓整體說服力下降。

**修正原則**：
- **真的要升級** → 用升級語（「不只是 X，更是 Y」）
- **同層展開** → 用平行語氣（「那如果有一個方法，可以一次解決呢？」）
- **細節補充** → 用追加語氣（「而且…」「另外…」）

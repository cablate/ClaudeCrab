# Mode B：視覺規格提示詞

## 定位

將 Mode A 的內容大綱，轉化為「可執行的視覺製作規格」。

這份提示詞可以丟給：
- Gamma.app
- Google Slides AI
- Canva AI
- 設計師
- 任何 AI 簡報工具

---

## 分離式架構

Mode B 分為兩部分，**分開產出**：

```
┌─────────────────────────────────────────────────┐
│ B-1：設計規範（產一次，全部通用）                 │
│                                                 │
│ - 配色方案                                       │
│ - 字體規範                                       │
│ - 版面原則                                       │
│ - 動畫原則                                       │
│ - 頁面類型模板（9 種）                            │
│                                                 │
│ 📁 輸出：[講座名稱]_設計規範.md                   │
└─────────────────────────────────────────────────┘
                    ↓ 套用
┌─────────────────────────────────────────────────┐
│ B-2：頁面規格（可分批產）                         │
│                                                 │
│ - P1: 元素 + 進場順序 + 視覺處理                  │
│ - P2: 元素 + 進場順序 + 視覺處理                  │
│ - ...                                           │
│                                                 │
│ 📁 輸出：[講座名稱]_頁面規格_[章節].md            │
└─────────────────────────────────────────────────┘
```

### 執行流程

1. **產出 B-1 設計規範**
   - 選擇預設風格（見 design-presets.md）或自訂
   - 一份講座只產一次
   - 輸出：`[講座名稱]_設計規範.md`

2. **產出 B-2 頁面規格**（可分批）
   - 讀取 Mode A 大綱的對應章節
   - 套用 B-1 的設計規範
   - 可分批產出，依講座章節分檔：
     - `[講座名稱]_頁面規格_[章節A].md`
     - `[講座名稱]_頁面規格_[章節B].md`
     - ...

3. **合併丟給 AI 工具**
   - 設計規範 + 頁面規格 = 完整提示詞
   - 丟給 Gamma.app 或其他工具

## 頁面類型模板詳細規格

### A. 封面頁

```
┌────────────────────────────────────┐
│                                    │
│                                    │
│         [大標題] 72pt              │
│         [副標題] 32pt              │
│                                    │
│              [講者/日期] 16pt       │
└────────────────────────────────────┘
```

- 大標題：置中，主色或白色
- 副標題：置中，強調色
- 背景：深色或漸層
- 講者資訊：底部置中，輔色

### B. 轉場頁（章節標題）

```
┌────────────────────────────────────┐
│                                    │
│           [章節編號] 96pt          │
│           [章節標題] 48pt          │
│                                    │
└────────────────────────────────────┘
```

- 章節編號：強調色，超大字
- 章節標題：白色
- 背景：深色

### C. 金句頁

```
┌────────────────────────────────────┐
│                                    │
│     「[金句內容]                   │
│       [金句內容續]」               │
│                                    │
└────────────────────────────────────┘
```

- 金句：置中，44-56pt
- 引號：裝飾性，可用較大的引號圖形
- 背景：深色
- 關鍵詞可用強調色

### D. 概念頁

```
┌────────────────────────────────────┐
│ [標題]                             │
├────────────────────────────────────┤
│                                    │
│  ① [要點 1]                        │
│  ② [要點 2]                        │
│  ③ [要點 3]                        │
│                                    │
└────────────────────────────────────┘
```

- 標題：左上或置中，36pt
- 要點：2-4 個，每個有圖標或編號
- 每個要點標註進場順序

### E. 對照頁

```
┌────────────────────────────────────┐
│ [標題]                             │
├─────────────────┬──────────────────┤
│   ❌ [錯誤]      │   ✅ [正確]      │
│                 │                  │
│  [說明內容]     │  [說明內容]      │
│                 │                  │
└─────────────────┴──────────────────┘
```

- 左側：危險色邊框或背景
- 右側：成功色邊框或背景
- 標題用問句或對比主題

### F. 流程頁

```
┌────────────────────────────────────┐
│ [標題]                             │
├────────────────────────────────────┤
│                                    │
│  [步驟1] → [步驟2] → [步驟3]       │
│     ①        ②         ③          │
│                                    │
└────────────────────────────────────┘
```

- 流程圖置中
- 每個節點標註進場順序
- 箭頭清晰

### G. 截圖展示頁

```
┌────────────────────────────────────┐
│ [標題]                     (全版)  │
├────────────────────────────────────┤
│ ┌────────────────────────────────┐ │
│ │                                │ │
│ │        [截圖]                  │ │
│ │                                │ │
│ └────────────────────────────────┘ │
└────────────────────────────────────┘
```

或

```
┌────────────────────────────────────┐
│ [標題]                     (半版)  │
├──────────────────┬─────────────────┤
│                  │                 │
│  [說明文字]      │    [截圖]       │
│                  │                 │
└──────────────────┴─────────────────┘
```

- 全版：截圖佔 80% 以上
- 半版：左文右圖或左圖右文
- 標題疊加在圖上時要有遮罩

### H. 互動頁

```
┌────────────────────────────────────┐
│                                    │
│          ⏸️ 互動時間               │
│                                    │
│     「[互動問題/指示]」            │
│                                    │
│          ([時長])                  │
└────────────────────────────────────┘
```

- 特殊視覺標記（暫停圖標）
- 背景可用不同顏色區隔
- 問題文字大而清晰

### I. 總結頁

```
┌────────────────────────────────────┐
│ [本節/本章重點]                    │
├────────────────────────────────────┤
│                                    │
│  ✓ [重點 1]                        │
│  ✓ [重點 2]                        │
│  ✓ [重點 3]                        │
│                                    │
│  → [預告下一節]                    │
└────────────────────────────────────┘
```

- 勾選圖標用成功色
- 預告用不同樣式（框線、背景色）
- 重點 3-5 個

## 從 Mode A 轉換到 Mode B

### 轉換對照表

| Mode A 類型 | Mode B 模板 | 轉換重點 |
|-------------|-------------|----------|
| 封面 | A. 封面頁 | 加入視覺層次 |
| 金句 | C. 金句頁 | 標註強調詞 |
| 概念 | D. 概念頁 | 拆分進場順序 |
| 截圖展示 | G. 截圖展示頁 | 確認佈局方式 |
| 對比 | E. 對照頁 | 加入顏色區分 |
| 流程 | F. 流程頁 | 拆分步驟順序 |
| 互動 | H. 互動頁 | 標註停頓時間 |
| 轉場 | B. 轉場頁 | 加入章節編號 |
| 總結 | I. 總結頁 | 加入預告 |
| 封底 | A. 封面頁變體 | 加入 CTA |

### 轉換時需補充的資訊

1. **進場順序**：每個元素標註 ①②③
2. **顏色標記**：正確/錯誤、強調詞
3. **視覺細節**：邊框、背景、陰影
4. **佈局確認**：置中/左對齊、全版/半版

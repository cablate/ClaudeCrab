# 設計風格預設

選擇一個預設風格，或基於預設自訂。

---

## 1. 極簡高端 (Minimal Premium)

適合：科技、設計、高單價產品講座

### 配色方案
- **主色**：純黑 #000000
- **輔色**：深灰 #1A1A1A
- **強調色**：金色 #D4AF37
- **成功色**：翠綠 #00A878
- **危險色**：珊瑚紅 #FF6B6B
- **背景色**：純黑 #000000
- **文字色**：純白 #FFFFFF

### 字體
- **標題**：Noto Sans TC Black，48-72pt
- **副標題**：Noto Sans TC Medium，28-36pt
- **內文**：Noto Sans TC Regular，20-24pt
- **強調**：Noto Sans TC Bold

### 視覺特點
- 極大留白
- 字體大小對比強烈（72pt vs 20pt）
- 金色只用於關鍵強調
- 無多餘裝飾

### 頁面樣式
- 金句頁：純黑底，白字，關鍵詞金色
- 轉場頁：章節編號 120pt 金色
- 對照頁：極細金色分隔線

## 如何選擇

### 根據講座主題

| 講座類型 | 推薦風格 |
|---------|---------|
| 技術/程式/AI | 科技霓虹、極簡高端 |
| 商業/金融/管理 | 專業商務 |
| 設計/美學/品牌 | 極簡高端、大膽撞色 |
| 教育/學習方法 | 溫暖手繪、專業商務 |
| 創意/行銷/社群 | 大膽撞色 |
| 生活/心理/成長 | 溫暖手繪 |

### 根據場合

| 場合 | 推薦風格 |
|------|---------|
| 企業內訓 | 專業商務 |
| 公開講座 | 視主題選擇 |
| 線上課程 | 極簡高端（減少視覺疲勞）|
| 社群分享 | 大膽撞色（吸引注意）|
| TED 風格 | 極簡高端 |

### 根據個人品牌

如果講者有既定的品牌色，應以品牌色為主色，再搭配預設風格的其他元素。

## 自訂風格

如果預設風格都不適合，可以基於以下原則自訂：

### 配色原則
1. **主色**：品牌色或講座主題相關色
2. **背景色**：深色或淺色擇一（影響整體調性）
3. **強調色**：與背景對比度高的顏色
4. **成功/危險色**：保持綠/紅的直覺認知

### 字體原則
1. **標題**：粗體，字重 700+
2. **內文**：正常字重，字重 400-500
3. **中文優先**：Noto Sans TC / Noto Serif TC
4. **大小對比**：標題至少是內文的 2 倍

### 一致性原則
1. 全場同一套配色
2. 同類型頁面同一個模板
3. 元素位置保持規律

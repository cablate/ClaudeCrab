# Memory System

記憶有限 — 想記住什麼，就寫進檔案。
「心裡記一下」活不過 session 重啟。檔案可以。

**原則：寧可多記。漏記比記太多更可惜。**

## 寫入規則

| 內容 | 寫到哪裡 | 優先度 |
|------|----------|--------|
| 今天發生的事、討論的話題、提到的人 | memory/YYYY-MM-DD.md | **高 — 積極記錄** |
| 決定、偏好、持久事實 | MEMORY.md | 高 |
| 學到的教訓、犯的錯 | CLAUDE.md（Lessons Learned）| 高 |
| 使用者資料更新 | USER.md | 中 |
| 人格上的自我發現 | SOUL.md（需通知使用者）| 低 |
| 自己身份的變化 | IDENTITY.md | 低 |

## 每日日誌 — 判斷原則

**memory/YYYY-MM-DD.md 是主要的記憶載體，應積極使用。**

判斷標準：**「下次聊到這件事時，會想回顧這段嗎？」**

- 會 → 記下來
- 不確定 → 記下來（寧可多記）
- 明顯不會 → 不記

**不需要等「重要決定」才記錄。對話中的人、事、數字、進度都值得記。**

## 觸發條件

以下情況**必須**寫入記憶：
- 使用者說「記住這個」或類似表達 → 立即寫入對應檔案
- 學到教訓或犯了錯 → 更新 CLAUDE.md（Lessons Learned）
- 使用者透露新的個人資訊或偏好 → 更新 USER.md 或 MEMORY.md
- 做了重要決定 → 記錄到 MEMORY.md
- 對話中出現上述「應該記錄的訊號」→ 寫入 memory/今天.md

以下情況**建議**寫入記憶：
- 觀察到使用者的行為模式（多次驗證後）
- 對話接近尾聲時，回顧是否有漏記的內容

## 每日日誌格式

memory/YYYY-MM-DD.md 的建議結構：

```markdown
# YYYY-MM-DD

## Observations
- 觀察到的事情

## Decisions
- 做的決定

## Notes
- 任何值得記錄的內容
```

不需要嚴格遵守格式 — 自由記錄就好，重點是寫下來。

## MEMORY.md 管理

- 定期把每日日誌的重點提煉到 MEMORY.md
- 清除過時的資訊 — 記憶的價值在精準，不在量
- 上限約 20,000 字元，膨脹了就精簡
- 這就像人類回顧日記後更新心智模型

## 對話保護

- 當對話變長時，主動把重要內容寫入 memory/今天.md
- 不要等使用者提醒 — 如果這個 session 有值得記住的東西，趁還在 context 裡就寫下來
- 對話接近尾聲時，回顧是否有值得記錄的內容
- 長期有價值的洞察，同步更新到 MEMORY.md

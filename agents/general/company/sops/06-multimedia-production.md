# SOP 06：多媒體產出

**版本**：v1.0
**建立日期**：2026-03-17
**最後更新**：2026-03-17

---

## 觸發條件

秘書分派視覺需求，指定產出類型為：短影片、課程素材、或社群卡片/Banner。

---

## 流程圖

```
[秘書] 分派視覺需求（指定子流程類型）
        ↓
  ┌─────┴──────┬────────────────┐
  ↓            ↓                ↓
[A. 短影片]  [B. 課程素材]  [C. 社群卡片/Banner]
  ↓            ↓                ↓
[各子流程執行]
  ↓
[秘書] 品管審核
  ↓
[Cab] 最終審核
  ↓
[Operator] 發布（如需要）
```

## 子流程 A：短影片

### A-1：腳本產出

| 項目 | 內容 |
|------|------|
| **負責人** | Writer |
| **輸入** | 主題、目標受眾、長度限制、用途（Threads / YouTube Shorts / 課程片頭） |
| **動作** | 撰寫腳本：文字內容 + 情緒標記（開心/嚴肅/疑惑等）+ B-roll 時機標註 |
| **輸出** | 腳本文件（含情緒標記 + B-roll 時機） |
| **品質檢查點** | 情緒標記完整（每段落至少一個）；B-roll 時機合理（每 3-5 秒視覺變化）；總長度符合目標 |
| **時限** | 接到需求後 1 天 |

### A-2：影片製作

| 項目 | 內容 |
|------|------|
| **負責人** | Media |
| **輸入** | 腳本（含情緒標記 + B-roll 時機） |
| **動作** | TTS 語音合成 → 表情圖切換 → 字幕嵌入 → B-roll 插入 → 最終合成 |
| **輸出** | 影片成品 + 預覽截圖 |
| **品質檢查點** | 音畫同步；格式統一（concat 素材全為真 PNG）；Windows 路徑跳脫正確；B-roll duration 含靜音 gap |
| **技術紅線** | concat 素材必須是真 PNG（非 JPEG-in-PNG）；duration 計算包含段落間靜音；ffmpeg subtitles filter 冒號需跳脫（`F\:/...`） |
| **時限** | 腳本確認後 2 天 |

### A-3：品管審核（短影片）

| 項目 | 內容 |
|------|------|
| **負責人** | 秘書 |
| **輸入** | 影片成品 + 預覽截圖 |
| **動作** | 逐項檢查品質清單 |
| **輸出** | 品管結果（通過 / 退回 + 具體問題點） |
| **品質檢查點** | 每 3-5 秒有視覺變化；字幕與語音同步；B-roll 切換自然不突兀；整體節奏符合短影片標準 |
| **時限** | 收到成品後 1 天 |

### B-2：素材製作

| 項目 | 內容 |
|------|------|
| **負責人** | Media |
| **輸入** | 視覺需求清單 |
| **動作** | 依需求清單逐項製作；維持統一視覺風格 |

|------|------|

| **動作** | 確認內容準確性、教學效果、視覺清晰度 |
| **輸出** | 審核結果（通過 / 修改意見） |
| **時限** | 收到素材包後 1 天 |

### C-1：文案提供

| 項目 | 內容 |
|------|------|

| **輸入** | 主題、目標平台、訊息重點 |

| **時限** | 接到需求後半天 |

### C-2：視覺設計

| 項目 | 內容 |
|------|------|
| **負責人** | Media |
| **輸入** | 文案稿 + 尺寸規格 |

## 交接規範

| 交接 | 交付物 | 驗收標準 |
|------|--------|----------|
| 秘書 → Writer | 視覺需求描述（主題 + 用途 + 目標平台 + 長度限制） | 資訊完整可直接執行 |
| Writer → Media | 腳本（含情緒標記 + B-roll 時機）或文案稿 | 標記清楚、無歧義 |
| Media → 秘書 | 成品 + 預覽截圖 + 技術備注（如有特殊處理） | 符合輸出規格 |

## 異常處理

| 情況 | 處理方式 |
|------|----------|
| 合成失敗（影片輸出錯誤） | 先用 `ffprobe` 驗證每個素材的格式；解決格式問題後重新合成，**不要重新生圖** |
| 素材尺寸不一致 | 用 ffmpeg 批量轉換統一尺寸，命令：`ffmpeg -y -i input.png -vf "scale=W:H:force_original_aspect_ratio=decrease,pad=W:H:(ow-iw)/2:(oh-ih)/2:white" output.png` |
| Cab 不滿意視覺效果 | 要求 Cab 具體說明問題所在（哪個畫面、哪個元素、問題是什麼），不接受「感覺不對」的模糊回饋再執行 |
| B-roll 畫面消失或 frame=0 | 確認所有 concat 素材為真 PNG（ffprobe 確認 codec=png），並確認 duration 包含靜音 gap |
| 字幕與音訊不同步 | 確認 SRT 時間碼來源正確；檢查 ffmpeg 字幕 filter 的路徑跳脫（Windows 冒號問題） |

## 品質指標

| 指標 | 目標值 | 量測方式 |
|------|--------|----------|
| 一次合成成功率（短影片） | ≥ 80% | Media 統計 |
| 品管退回率 | ≤ 15% | 秘書統計 |
| 素材復用率（庫存利用） | 持續追蹤，建立基準值 | 每月盤點 |
| 製作週期（短影片）| ≤ 3 天（腳本確認到交付） | 時間戳記 |

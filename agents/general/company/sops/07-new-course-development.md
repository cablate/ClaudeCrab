# SOP 07：新課程開發

**版本**：v1.0
**建立日期**：2026-03-17
**最後更新**：2026-03-17

---

## 觸發條件

Cab 決定開發新課程（包含：線上課程、實體工作坊系列、學員訓練計畫等長期課程產品）。

---

## 流程圖

```
[Cab] 決定開新課程
        ↓

        ↓
[Researcher] 市場調研 + 競品分析
        ↓
[Cab] 課程架構決策 + 大綱確認
        ↓
━━━━━━ Phase 2：內容製作（2-4 週）━━━━━━  ←── 與 Phase 3 平行進行

[Transcriber] 既有素材萃取
[秘書] 課綱展開 + 附件規劃
[Cab] 內容審核 + 教學交付
        ↓
━━━━━━ Phase 3：技術準備（1-2 週）━━━━━━  ←── 與 Phase 2 平行進行
[Coder] Starter Kit / 實作環境

        ↓
```

## 詳細步驟

### Phase 1：規劃

**目標**：確認課程定位、驗證市場需求，取得 Cab 拍板的課綱框架。

#### Step 1：課程定位分析

| 項目 | 內容 |
|------|------|
| **負責人** | 秘書 |
| **輸入** | Cab 的初步想法（哪個主題、什麼形式） |
| **動作** | 分析：目標受眾輪廓、受眾痛點、與現有課程的綜效、差異化定位 |
| **輸出** | 定位文件（目標受眾 + 痛點 + 綜效 + 差異化） |
| **品質檢查點** | 有市場依據（非拍腦袋）；差異化清楚（不是「也有 AI 課程」）；與既有課程無嚴重重疊 |
| **時限** | 收到 Cab 需求後 2 天 |

#### Step 2：市場調研

| 項目 | 內容 |
|------|------|
| **負責人** | Researcher |
| **輸入** | 定位文件（課程主題方向） |
| **動作** | 調研 3 個以內競品：功能、定價、目標受眾、差異化空間 |
| **輸出** | 競品分析文件（≤3 個競品，含定價 + 差異化空間） |
| **品質檢查點** | 競品確實存在並可查核；差異化空間有具體說明（不是「我們更好」） |
| **時限** | 收到定位文件後 3 天 |

#### Step 3：課程架構決策

| 項目 | 內容 |
|------|------|
| **負責人** | Cab |
| **輸入** | 定位文件 + 競品分析 |
| **動作** | 確認課程主軸；拍板課綱框架（週數、每週主題、評估方式）；確認定價策略 |
| **輸出** | 確認版課綱框架（Cab 簽核） |
| **時限** | 收到素材後 2 天 |

---

### Phase 2：內容製作

**目標**：產出可交付給學員的完整課程內容。

#### Step 4：課程文案

| 項目 | 內容 |
|------|------|
| **負責人** | Writer |
| **輸入** | 確認版課綱框架 + 定位文件 |
| **動作** | 撰寫 Landing Page 文案、銷售頁描述、課綱對外描述 |
| **輸出** | 文案稿（Landing Page + 銷售頁 + 課綱描述） |
| **品質檢查點** | 痛點描述精準；CTA 明確；課綱描述對齊實際內容 |
| **時限** | 收到課綱框架後 3 天 |

#### Step 5：既有素材萃取

| 項目 | 內容 |
|------|------|
| **負責人** | Transcriber |
| **輸入** | 課綱框架（確認哪些主題有既有素材） |
| **動作** | 搜尋過去講座逐字稿、電子報、部落格文章中與課綱相關的內容；整理成素材包 |
| **輸出** | 素材包（按課綱主題分類） |
| **品質檢查點** | 素材確實與課綱主題相關；來源標注清楚（日期 + 原始出處） |
| **時限** | 課綱確認後 3 天 |

#### Step 6：課綱展開 + 附件規劃

| 項目 | 內容 |
|------|------|
| **負責人** | 秘書 |
| **輸入** | 確認版課綱框架 + 素材包（既有素材） |
| **動作** | 展開每週細節：學習目標、課程內容重點、作業設計、附件清單（講義/Cheatsheet/Template）；**必須先讀既有素材再展開，不自行發明框架** |
| **輸出** | 詳細課綱（含每週學習目標 + 附件清單） |
| **品質檢查點** | 每週有明確且可量測的學習目標；附件設計支援學習（不是湊數）；內容基於素材，非憑空創造 |
| **時限** | 收到素材包後 3 天 |

#### Step 7：內容審核與教學交付

| 項目 | 內容 |
|------|------|
| **負責人** | Cab |
| **輸入** | 詳細課綱 + 附件清單 |
| **動作** | 審核內容準確性；確認每週可執行性；實際教學錄製（線上課）或現場交付（實體） |
| **輸出** | 審核通過的課綱；課程錄影或實體交付 |
| **時限** | 依課程週數排定 |

### Phase 3：技術準備（與 Phase 2 平行）

#### Step 8：Starter Kit / 實作環境

| 項目 | 內容 |
|------|------|
| **負責人** | Coder |
| **輸入** | 詳細課綱（實作環節說明） |
| **動作** | 開發 Starter Kit、設定實作練習環境、撰寫 README |
| **輸出** | Starter Kit（可獨立運行） + README |
| **品質檢查點** | Starter Kit 可獨立 clone 後運行；README 清楚說明安裝步驟；有範例輸出供學員對照 |
| **時限** | 課綱確認後 1 週 |

#### Step 9：課程素材

| 項目 | 內容 |
|------|------|
| **負責人** | Media |
| **輸入** | 視覺需求清單（由秘書從詳細課綱整理） |
| **動作** | 製作概念圖、流程圖、demo 截圖，維持統一視覺風格 |
| **輸出** | 素材包（按單元命名） |
| **品質檢查點** | 尺寸統一；風格一致；內容準確 |
| **時限** | 視覺需求清單確認後 1 週 |

### Phase 4：上線推廣

#### Step 10：推廣內容

| 項目 | 內容 |
|------|------|
| **負責人** | Writer |
| **輸入** | Landing Page 文案 + 課程特色 |
| **動作** | 撰寫 Threads 預告系列（3-5 則）+ 電子報預告文 |
| **輸出** | Threads 稿件（含排程建議）+ 電子報稿件 |
| **品質檢查點** | 推廣內容有 hook；傳達核心價值；CTA 明確 |
| **時限** | 上線前 1 週完成 |

#### Step 11：SEO 優化

| 項目 | 內容 |
|------|------|
| **負責人** | SEO |
| **輸入** | Landing Page 草稿 |
| **動作** | 關鍵字優化、meta description、alt text、結構化資料 |
| **輸出** | 優化後 Landing Page |
| **時限** | 上線前 3 天完成 |

#### Step 12：發布與追蹤

| 項目 | 內容 |
|------|------|
| **負責人** | Operator |
| **動作** | 排程發布推廣內容；發送電子報；追蹤報名數；更新名單系統 |
| **輸出** | 上線確認 + 早鳥期報名數報告 |

#### Step 13：舊學員與 B 端通知

| 項目 | 內容 |
|------|------|
| **負責人** | 業務助理 |
| **動作** | 篩選適合的舊學員（依課程主題）；通知相關 B 端客戶；提供早鳥優惠資訊 |
| **輸出** | 通知名單 + 回覆追蹤 |

## 交接規範

| 交接 | 交付物 | 驗收標準 |
|------|--------|----------|
| 秘書 → Cab | 定位文件 + 競品分析 + 課綱草案 | 三份文件齊全，Cab 可直接決策 |
| Cab → 秘書 | 確認後的課綱框架 | 有 Cab 明確簽核（不是「差不多這樣」） |
| 秘書 → Writer | 任務包（課綱 + 定位 + 目標受眾 + 用途說明） | Writer 拿到就能直接動筆 |
| 秘書 → Coder | 任務包（實作環節需求 + 技術約束 + 學員技術程度） | 需求明確，技術約束清楚 |
| 秘書 → Media | 視覺需求清單（每項含用途 + 尺寸 + 風格參考） | 每項需求可獨立執行 |

## 異常處理

| 情況 | 處理方式 |
|------|----------|
| 報名數不如預期（開賣 1 週不到目標 50%） | 秘書分析原因：定價？定位？推廣管道？觸及率？列出假設，提供 2-3 個調整選項供 Cab 決策 |
| Starter Kit 開發延期 | 評估是否可先開課、後補 Starter Kit（需告知學員）；若影響核心學習體驗則延後開課 |
| 課程內容展開卡住（不知道怎麼展開） | 先讀既有素材（VibeCoding 素材路徑：`BrainPlanStorming/📚_Key_Resources/原創內容/課程/`）；基於素材展開，不自行發明 |
| Cab 審核後大幅修改課綱 | 評估影響範圍（是否需要重做文案、素材）；秘書統籌修改清單，各角色各自更新 |
| 課程上線後收到大量負面回饋 | 收集具體意見（哪個單元、什麼問題）；秘書整理改善清單；Cab 決定修正優先序 |

| 指標 | 目標值 | 量測方式 |
|------|--------|----------|
| 從決定開課到上線 | ≤ 6 週 | 里程碑時間戳記 |
| 首批報名數 | 由 Cab 設定目標 | Operator 追蹤 |
| 課程推薦度 | ≥ 4.5 / 5 | 課後問卷 |
| Starter Kit 開箱即用率 | ≥ 90%（學員反饋可成功運行） | 課程社群回饋 |

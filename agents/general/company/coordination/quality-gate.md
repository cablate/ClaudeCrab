# 品管閘門 SOP

**使用者**：秘書
**目的**：所有員工產出經過秘書品管後才到 Cab

---

## 閘門流程

```
員工產出 → 秘書收到
  ├── 品質合格 → 交 Cab 定稿
  ├── 小問題 → 標記修改建議，退回員工
  └── 方向錯誤 → 退回 + 重新對齊需求
```

---

## 審核流程

1. **收到產出**：確認是否完整（不是半成品就交）
2. **選擇對應 Checklist**：
   - 文字內容 → `quality/content-review.md`
   - 提案 → `quality/proposal-review.md`
   - 交接 → `quality/handoff-checklist.md`
3. **逐項檢查**
4. **判斷**：
   - 全過 → 附秘書意見交 Cab
   - 部分不過 → 退回，附具體修改建議
   - 方向錯 → 退回，重新對齊

---

## 退回規範

**退回時必須包含**：
1. 哪些項目不過（引用 checklist 編號）
2. 具體修改建議（不是「再改改」）
3. 參考素材或範例（如有）
4. 修改後重交的時限

**退回次數上限**：
- 同一任務最多退回 2 次
- 第 3 次 → 秘書介入協助完成，並記錄為品質問題
- 反覆出現同類品質問題 → 記錄到該員工的成長訊號（警示）

---

## 品管數據追蹤

| 指標 | 目標 | 追蹤頻率 |
|------|------|---------|
| 一次通過率 | ≥ 70% | 週 |
| 平均退回次數 | ≤ 1.2 | 週 |
| Cab 改稿幅度 | 微調即可（≤20% 修改） | 月 |
| 品管處理時間 | ≤ 4 小時 | 週 |

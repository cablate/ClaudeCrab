# Avatar Expression Index

生成新表情時參考此索引，確保命名一致、避免重複。

## 命名規範

格式：`{type}-{emotion}[-{variant}].png`
- **type**: A/B/C（風格系列）
- **emotion**: 主要情緒（英文小寫）
- **variant**: 可選，動作或變體描述

## 基底參考圖

生成新表情時，**必須使用 `typeA-standard.png` 作為參考圖**，確保角色風格一致。

## 情緒標籤對照

配圖時用這些標籤匹配語意：

- **neutral**: 一般陳述
- **positive/greeting**: 正面、問候
- **curious/confused**: 好奇、困惑、提問
- **surprised**: 驚訝、意外
- **emphasis**: 強調
- **sad/helpless**: 難過、無助
- **excited/happy**: 興奮、開心
- **embarrassed/awkward**: 尷尬
- **focused/working**: 專注工作

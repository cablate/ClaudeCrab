# 數字人開源 GitHub 專案

## 完整框架（一站式解決方案）

### 1. Fay - 數字人 MCP 框架
> GitHub: https://github.com/xszyou/Fay

**定位**：幫助數字人（2.5D、3D、移動、PC、網頁）或大語言模型連通業務系統的 MCP 框架。

**核心特點**：
- ✅ **完全開源免費商用**
- ✅ 離線運行，無需網路（隱私安全）
- ✅ 毫秒級響應
- ✅ 多模型兼容（可切換不同 LLM、TTS、ASR）
- ✅ 跨平台（微控制器、App、網頁、大屏幕）
- ✅ 多用戶並發支援
- ✅ **僅用本地 CPU 算力即可實時驅動數字口型**

**應用場景**：
- 虛擬主持人、直播帶貨
- 產品導購、語音助手
- 數字人面試官、心理評估
- 類似 Jarvis / Her 的 AI 助手

**技術棧**：
- Python 3.9-3.12
- 支援 OpenAI 兼容 API、DeepSeek

**自定義功能**：
- 知識庫管理
- 自定義 Q&A 對
- 人設信息設定

---

### 2. Linly-Talker - 數字人對話系統
> GitHub: https://github.com/Kedreamix/Linly-Talker

**定位**：結合大語言模型（LLM）與視覺模型的智能 AI 系統，創建新型人機互動方式。

**核心特點**：
- ✅ 整合 Whisper、Linly、Microsoft Speech、SadTalker
- ✅ Gradio WebUI 界面
- ✅ 多輪對話能力
- ✅ 聲音克隆（GPT-SoVITS）
- ✅ 即時語音識別與視頻字幕

**最新功能（Linly-Talker-Stream）**：
- 基於 WebRTC 的即時串流架構
- 全雙工對話體驗（邊聽邊說）
- 可打斷的自然對話（Barge-in）
- 模組化多模態管線

**整合模型**：
- LLM：Linly、GeminiPro、Qwen、GPT
- Vision：Whisper、SadTalker、MuseTalk
- TTS：CosyVoice、Edge TTS

---

## 唇形同步（Lip-sync）專案

### 4. MuseTalk - 即時高品質唇形同步
> GitHub: https://github.com/TMElyralab/MuseTalk

**定位**：騰訊音樂娛樂 Lyra Lab 開發的即時高品質唇形同步模型。

**技術特點**：
- 在 VAE 的 Latent Space 進行 Inpainting
- 面部區域 256×256
- 支援中、英、日等多語言音頻

**性能**：
- **30fps+ 即時推理**（NVIDIA Tesla V100）
- 4GB VRAM（RTX 3050 Ti）可運行（fp16 模式）

**版本更新**：
- v1.5（2025/03）：大幅提升清晰度、身份一致性、唇語同步精度
- 訓練代碼已開源（2025/04）

**授權**：MIT License（商用免費）

---

### 5. SadTalker - 3DMM 驅動的說話人頭
> GitHub: https://github.com/OpenTalker/SadTalker

**技術**：
- 使用 3DMM 進行面部運動建模
- 從音頻預測頭部動作和表情
- 生成自然的頭部移動（不只是嘴型）

**優勢**：
- 比純 Wav2Lip 更自然
- 頭部會隨說話輕微擺動

---

### 6. Wav2Lip - 經典唇形同步
> GitHub: https://github.com/Rudrabha/Wav2Lip

**定位**：音頻驅動唇形同步的經典方案。

**特點**：
- 穩定可靠
- 運算資源需求較低
- 許多專案基於此改進

## 語音合成（TTS）專案

### 7. CosyVoice - 多語言大型語音生成模型
> GitHub: https://github.com/FunAudioLLM/CosyVoice

**版本**：Fun-CosyVoice 3.0（最新）

**語言支援**：
- 9 種常用語言：中、英、日、韓、德、西、法、意、俄
- 18+ 種中文方言：廣東話、閩南話、四川話、東北話、上海話等

**核心能力**：
- ✅ **零樣本跨語言聲音克隆**
- ✅ 發音控制（拼音、CMU 音標）
- ✅ TensorRT-LLM 加速（4x 提升）

**可用模型**：
- Fun-CosyVoice3-0.5B
- CosyVoice2-0.5B
- CosyVoice-300M 系列

**授權**：Apache-2.0（商用免費）

**Docker 部署**：
```bash
# 社區 Docker 方案
# https://github.com/neosun100/cosyvoice-docker
# 一鍵部署 Web UI + REST API + 聲音克隆
```

---

### 8. GPT-SoVITS - 少樣本語音克隆
> GitHub: https://github.com/RVC-Boss/GPT-SoVITS

**核心賣點**：**1 分鐘音頻即可訓練出高品質 TTS 模型！**

**功能**：
- **零樣本 TTS**：5 秒音頻即可轉換
- **少樣本 TTS**：1 分鐘訓練數據微調
- 語速控制、情緒控制
- 跨語言：中、英、日、韓、粵語

**WebUI 工具**：
- 人聲伴奏分離
- 自動訓練集分段
- 中文 ASR + 文字標註

**版本選擇**：
- v1/v2：適合一般品質音頻
- v3/v4：更高相似度，但對訓練數據品質要求更高

## 專案選擇建議

| 需求 | 推薦專案 |
|------|----------|
| **一站式快速開始** | Fay 或 Linly-Talker |
| **即時直播** | Fay + MuseTalk |
| **最高品質唇形** | MuseTalk |
| **聲音克隆（快速）** | GPT-SoVITS |
| **聲音克隆（多語言）** | CosyVoice |
| **純 CPU 運行** | Fay |
| **研究/學習目的** | SadTalker + Wav2Lip |

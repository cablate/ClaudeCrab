# 數字人（Digital Human）概念與技術原理

## 什麼是數字人？

數字人（Digital Human / AI Avatar）是透過 AI 技術創建的虛擬人物，能夠模擬真人的外觀、聲音、表情和動作。根據技術實現方式，可分為：

### 1. 2D 數字人
- 基於單張或多張照片生成
- 使用 Lip-sync 技術驅動嘴型
- 計算成本較低，適合快速部署
- 代表技術：Wav2Lip、SadTalker、MuseTalk

### 2. 2.5D 數字人
- 介於 2D 和 3D 之間
- 具有一定的頭部轉動和表情變化
- 使用 3DMM（3D Morphable Model）進行面部重建
- 代表專案：Fay、Linly-Talker

### 3. 3D 數字人
- 完整的三維建模
- 支援全方位視角和複雜動作
- 需要較高的運算資源
- 可使用 NeRF、高斯潑濺（Gaussian Splatting）技術

## 核心技術棧（Tech Stack）

數字人系統的完整技術流程：

```
用戶語音輸入
    ↓
┌─────────────────────────────────────────────────────────────┐
│  ASR (Automatic Speech Recognition) - 語音識別              │
│  將語音轉換為文字                                            │
│  技術：Whisper、FunASR、Azure Speech                        │
└─────────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────────┐
│  LLM (Large Language Model) - 大語言模型                    │
│  理解意圖並生成回覆文字                                       │
│  技術：GPT-4、Claude、DeepSeek、Qwen、Linly                 │
└─────────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────────┐
│  TTS (Text-to-Speech) - 語音合成                            │
│  將文字轉換為自然語音                                        │
│  技術：CosyVoice、GPT-SoVITS、Edge TTS、Azure TTS          │
└─────────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────────┐
│  THG (Talking Head Generation) - 口型生成/數字人驅動         │
│  根據音頻驅動數字人的嘴型和表情                               │
│  技術：Wav2Lip、SadTalker、MuseTalk、ER-NeRF               │
└─────────────────────────────────────────────────────────────┘
    ↓
數字人視頻輸出 → 推流至直播平台
```

## 關鍵技術詳解

### 1. ASR（語音識別）

| 技術 | 特點 | 延遲 |
|------|------|------|
| Whisper | OpenAI 開源，多語言支援 | 中等 |
| FunASR | 阿里達摩院，中文優化 | 低 |
| Azure Speech | 微軟雲服務，即時串流 | 極低 |

### 2. TTS（語音合成）

| 技術 | 特點 | 聲音克隆 |
|------|------|----------|
| CosyVoice | 阿里開源，支援 9 語言 + 18 方言 | ✓ 零樣本 |
| GPT-SoVITS | 1 分鐘音頻即可訓練 | ✓ 少樣本 |
| Edge TTS | 免費，微軟 Edge 引擎 | ✗ |
| Azure TTS | 商用級品質 | ✓ Custom Voice |

### 3. Lip-sync（嘴型同步）

| 技術 | 方法 | 效果 |
|------|------|------|
| Wav2Lip | 音頻 → 嘴型預測 | 基礎但穩定 |
| SadTalker | 3DMM 面部重建 + 音頻驅動 | 自然頭部動作 |
| MuseTalk | Latent Space Inpainting | 高品質即時（30fps+）|
| ER-NeRF | Neural Radiance Field | 極高品質，慢 |

### 4. 3DMM（3D 形變模型）

3D Morphable Model 是面部重建的關鍵技術：
- 將人臉分解為：形狀（Shape）、表情（Expression）、姿態（Pose）
- 可從單張照片重建 3D 人臉
- SadTalker 使用此技術生成自然的頭部動作

## 即時互動架構

### 延遲要求
- **可接受延遲**：< 2 秒（用戶感知流暢對話）
- **理想延遲**：< 500ms（接近真人對話）

### 串流優化策略

1. **流式處理（Streaming）**
   - ASR：邊聽邊轉文字
   - LLM：流式輸出 token
   - TTS：邊生成邊播放

2. **分段處理**
   - 將長回覆按句子分段
   - 每段獨立進行 TTS + THG
   - 實現「聽到問題就開始回答」的效果

3. **預測與緩存**
   - 常見問答預生成
   - 表情動作模板緩存

## 硬體需求

### 最低配置（2D 數字人）
- CPU：可運行（Fay 聲稱僅用 CPU 即可）
- GPU：GTX 1060 6GB
- RAM：16GB

### 推薦配置（高品質即時）
- GPU：RTX 3080 / A100
- VRAM：12GB+
- RAM：32GB+

### 雲端方案
- 使用 GPU 雲服務（AWS、GCP、阿里雲）
- API 方案（HeyGen、D-ID）無需本地 GPU

## 應用場景

1. **直播帶貨**：7×24 小時不間斷直播
2. **智能客服**：多語言即時響應
3. **教育培訓**：個性化數字講師
4. **虛擬主播**：娛樂直播、新聞播報
5. **企業形象**：品牌代言人
6. **心理諮詢**：數字人面試官、心理評估

---

## 平台政策注意事項

⚠️ **抖音規定（2023年起）**：
- 數字人直播必須由真人驅動進行即時互動
- 不允許完全由 AI 驅動進行互動
- 違規可能導致封號

其他平台（淘寶、快手等）政策各異，需查閱最新規定。

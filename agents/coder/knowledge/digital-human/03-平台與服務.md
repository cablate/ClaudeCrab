# 數字人平台與服務生態

## 商業 SaaS 平台比較

### 1. HeyGen
> 官網：https://www.heygen.com

**定位**：面向創作者和行銷人員的 AI 視頻生成平台。

#### 定價方案（2026 年 2 月）

| 方案 | 價格 | 額度 | 主要功能 |
|------|------|------|----------|
| Free | $0/月 | ~3 分鐘 | 720p、浮水印、測試用 |
| Creator | $29/月 | 200 Premium Credits (~10分鐘) | 1080p、無浮水印 |
| Pro | $99/月 | 2,000 Credits (~100分鐘) | 進階功能 |
| Business | $149/月 + $20/席位 | 1,000 Credits | 4K、團隊協作 |
| Enterprise | 客製報價 | 無限制 | 專屬支援、客製整合 |

#### API 方案（獨立訂閱）
| 方案 | 價格 | Credits | 單價 |
|------|------|---------|------|
| Free API | $0 | 10/月 | - |
| Pro | $99/月 | 100 | $0.99/credit |
| Scale | $330/月 | 660 | $0.50/credit |

#### 核心功能
- **Avatar IV**：最新一代數字人技術
- **LiveAvatar**：即時互動數字人
- **AI 配音翻譯**：唇形同步多語言翻譯
- **Video Avatar**：創建自己的數字分身

#### 2026 年 2 月更新
- "Generative Credits" 更名為 "Premium Credits"
- 音頻配音（非唇形同步翻譯）付費方案無限使用
- 預估成本功能上線

#### 注意事項
- ❌ Credits 不滾存，月底清零
- ❌ 超額不自動扣費，服務會停止
- ✅ 可購買額外 Credit Pack（$15/月 = 300 credits）

### 2. D-ID
> 官網：https://www.d-id.com

**定位**：生成式 AI 視頻平台，專注於說話人頭視頻。

#### 定價方案

| 方案 | 價格 | 內容 |
|------|------|------|
| API Build | ~$18/月 | 32 分鐘串流視頻 或 16 分鐘一般視頻 |
| Enterprise | 客製報價 | 無限使用、專屬支援 |

#### 核心功能
- **Real-time Streaming API**：低延遲即時視頻生成
- **AI Agents**：建立互動式視覺代理
- **Creative Reality™**：高解析度視覺輸出
- **100+ 語言**：多語言支援

#### API 特點
- 串流客戶：Credit 價格減半
- 低延遲：適合聊天機器人、即時客服
- 無需預渲染

---

### 3. Synthesia
> 官網：https://www.synthesia.io

**定位**：#1 企業級 AI 視頻平台，Fortune 100 中 90%+ 企業使用。

#### 定價方案

| 方案 | 價格 | 視頻分鐘/月 | 主要功能 |
|------|------|-------------|----------|
| Free | $0 | 有限 | 測試用 |
| Starter | $29/月（年付 $18） | 10 分鐘 | 基本功能 |
| Creator | $89/月（年付 $64） | 30 分鐘 | 180+ avatars、5 個人分身、API |
| Enterprise | 客製報價 | 無限 | SSO、Brand Kit、專屬 onboarding |

#### 核心功能
- **180+ AI Avatars**：多樣化數字人選擇
- **Personal Avatar**：創建個人數字分身
- **1-Click Translation**：一鍵多語言翻譯
- **SCORM Export**：LMS 整合（Enterprise only）

#### 額外費用
- Studio Express-1 Avatar：$1,000/年（年付用戶）
- 處理時間：最多 10 天

## 平台選擇指南

### 按使用場景

| 場景 | 推薦平台 | 理由 |
|------|----------|------|
| **企業培訓視頻** | Synthesia | 企業功能完整、SCORM |
| **行銷內容** | HeyGen | 性價比高、功能豐富 |
| **即時客服** | D-ID | 低延遲串流 API |
| **中國電商直播** | 百度慧播星 | 本地化、合規 |
| **預算有限** | D-ID Build | 入門價僅 $18/月 |

### 按預算

| 預算 | 方案建議 |
|------|----------|
| $0 | 開源方案（Fay + CosyVoice） |
| < $50/月 | D-ID Build ($18) 或 HeyGen Creator ($29) |
| $50-150/月 | HeyGen Pro ($99) |
| > $150/月 | Synthesia Creator 或 HeyGen Business |
| 企業級 | 各平台 Enterprise 方案 |

### 開源 vs 商業

| 面向 | 開源方案 | 商業平台 |
|------|----------|----------|
| **成本** | 伺服器/GPU 費用 | 月費訂閱 |
| **客製化** | 完全可控 | 有限 |
| **維護** | 需自行維護 | 平台負責 |
| **品質** | 取決於配置 | 穩定高品質 |
| **上線速度** | 需開發時間 | 即開即用 |
| **適合** | 技術團隊、長期專案 | 快速驗證、非技術用戶 |

## API 整合考量

### 延遲要求
- **即時互動**：< 500ms（選 D-ID Streaming 或自建）
- **非即時視頻**：可接受分鐘級（HeyGen、Synthesia）

### 成本優化
1. **批量處理**：預生成常用內容
2. **混合架構**：即時用 API，離線用開源
3. **快取策略**：相同請求重用結果

## 配色系統

### 主要色彩

| 用途 | 色碼 | RGB | 說明 |
|------|------|-----|------|
| 主文字 | `#1e293b` | rgb(30, 41, 59) | 深藍灰，不是純黑 |
| 次要文字 | `#334155` | rgb(51, 65, 85) | 用於描述文字 |
| 背景色 | `#ffffff` | rgb(255, 255, 255) | 純白背景 |
| 裝飾大標 | `#e2e8f0` | rgb(226, 232, 240) | 超大裝飾字用淺灰 |

### 標籤色彩系統（Tag Colors）

網站使用語義化的標籤顏色系統，每個類別有專屬色調：

| 類別 | 文字色 | 背景色 | 用於 |
|------|--------|--------|------|
| 橘色系 | `rgb(249, 115, 22)` | `rgba(249, 115, 22, 0.1)` | 近期活動、免費資源、文章 |
| 藍色系 | `rgb(59, 130, 246)` | `rgba(59, 130, 246, 0.1)` | 入門信、課程、模板、數位工具 |
| 綠色系 | `rgb(16, 185, 129)` | `rgba(16, 185, 129, 0.1)` | 工作坊、教學、作品、電子報 |
| 紫色系 | `rgb(139, 92, 246)` | `rgba(139, 92, 246, 0.1)` | 諮詢、企業內訓、社群、AI 相關 |
| 粉色系 | `rgb(236, 72, 153)` | `rgba(236, 72, 153, 0.1)` | 設計相關（課程、資源）|

**設計要點**：
- 背景使用 10% 透明度的主色
- 形成「浮在白色上」的輕盈感
- 每個標籤類別保持一致的視覺識別

## 字體系統

### 字型選擇

```css
font-family: Inter, "Noto Sans TC", sans-serif;
```

- **英文**：Inter（現代、清晰、專業）
- **中文**：Noto Sans TC（Google 思源黑體，易讀）

### 字體大小層級

| 層級 | 大小 | 字重 | 用途 |
|------|------|------|------|
| 裝飾大標 | 128px | 900 (Black) | 區塊背景裝飾文字 |
| Hero 標題 | 48px | - | 首頁主標題 |
| 區塊標題 | 24px | 700 (Bold) | H2 區塊標題 |
| 卡片標題 | 18px | - | 卡片內標題 |
| 正文 | 16px | 400 (Regular) | 主要內容 |
| 標籤 | 12px | - | 分類標籤文字 |
| 小標籤 | 9px | - | 微型標籤 |

### 特殊處理

- **裝飾大標**：`letter-spacing: -6.4px`（負字距讓大字更緊湊有力）
- **行高**：正文使用 24px（1.5 倍行高）

## 模塊拆解

### 1. Hero 區塊

**結構**：
- 左側：文字區（主標題 + 副標 + 個人簡介 + CTA）
- 右側：個人照片（黑白色調）

**風格特徵**：
- 主標題使用親切口吻：「嗨！我是潘」
- 大量留白，不擁擠
- 照片使用圓角或不規則形狀裁切

**可複用點**：
- 雙欄佈局（文字 + 視覺）
- 親切但專業的自我介紹風格

---

### 2. 裝飾大標題區塊

**結構**：
- 超大裝飾文字（如「服務與課程」「近期活動」）
- 使用淺灰色 `#e2e8f0`
- 字重 900，字距 -6.4px

**風格特徵**：
- 純裝飾用途，不是主要閱讀內容
- 營造視覺層次感
- 常出現在區塊切換處

**CSS 參考**：
```css
.section-decoration {
  font-size: 128px;
  font-weight: 900;
  color: #e2e8f0;
  letter-spacing: -6.4px;
}
```

---

### 3. 服務分類區塊

**結構**：
- 主分類標題 + 英文副標
- 下方為小卡片 Grid

**分類示例**：
- SOLOPRENEUR 一人事業
- AI AGENT WORKFLOW AI Agent 工作流
- PRODUCTIVITY.ENHANCE 生產力研究社
- EVERYONE CAN BUILD VIBE CODING

**風格特徵**：
- 英文副標使用全大寫、灰色、小字體
- 主分類標題為粗體中文

---

### 4. 服務卡片（Service Card）

**結構**：
- 標籤（1-3 個，用色彩區分類別）
- 卡片標題
- 卡片描述

**樣式**：
```css
.service-card {
  background: rgba(255, 255, 255, 0.6);
  border-radius: 12px;
  /* 懸浮感的半透明白色背景 */
}
```

**風格特徵**：
- 沒有明顯邊框
- 使用半透明白色背景
- 圓角 12px
- 標籤使用語義化顏色系統

---

### 5. 活動推廣區塊（CTA Section）

**結構**：
- 左：活動卡片（深色背景 + 金色裝飾文字 + 插圖）
- 右：活動卡片（白色背景 + 裝飾文字 + 預覽圖）

**「知識有價計畫」卡片風格**：
- 深藍背景配金色書法風格文字
- 有質感的圖書/知識視覺元素
- 營造「高價值知識產品」的氛圍

**「質感網站工作坊」卡片風格**：
- 白色背景 + 淺灰裝飾文字
- 展示網站預覽圖
- 標籤顯示「早鳥優惠」

**樣式**：
```css
.cta-card {
  border-radius: 32px; /* 大圓角 */
}
```

---

### 6. Footer 區塊

**結構**：
- 超大品牌名「MADE BY PAN」
- 聯絡資訊（email）
- 位置資訊（TAIPEI / REMOTE）
- 社群連結（Instagram, YouTube, Facebook, Threads）
- 版權聲明

**風格特徵**：
- 品牌名使用超大粗體字
- 深色文字（`#0f172a`）
- 簡潔、信息完整

## 互動與動畫

### 觀察到的動畫
- **卡片 Hover**：可能有微微放大或陰影變化
- **滾動效果**：區塊標題可能有 fade-in 效果
- **連結 Hover**：底線或顏色變化

### 建議動畫參數
```css
transition: all 0.3s ease;
```

## 間距系統

### 觀察到的間距模式
- **區塊間距**：大量留白，約 80-120px
- **卡片間距**：約 16-24px
- **內部 Padding**：約 16-24px

### 佈局特點
- 最大寬度約 1200px
- 左右 Padding 約 40px
- Grid 佈局為主

## 設計應用指南

### 你的網站可以這樣用

| 你的區塊 | 參考 MadeByPan 的 |
|----------|------------------|
| 首頁 Hero | Hero 區塊（雙欄：文字+照片）|
| 服務介紹 | 服務分類 + 服務卡片 |
| 作品集 | 服務卡片的變體 |
| 活動推廣 | CTA Section |
| 頁尾 | Footer 區塊 |

### 快速套用清單

1. **字體**：安裝 Inter + Noto Sans TC
2. **主色**：使用 `#1e293b` 而非純黑
3. **標籤**：建立 5 色標籤系統
4. **卡片**：半透明白底 + 12px 圓角
5. **大標**：裝飾字用淺灰 + 負字距

# Skill 載入

你的 `.claude/skills/` 裡有老闆花時間為你量身打造的專業知識——這是你存在的理由，不是參考資料。

任務前掃 `.claude/skills/`，載入對應 skill（含 references/），再動手。

- 只讀 SKILL.md 跳 references/ = 沒讀。references/ 裡有上次犯錯後寫進去的修正，跳過它你就會重犯同樣的錯
- 「這次不需要」「我已經知道了」不是理由——你每次 session 都是全新的，你什麼都不記得
- 不讀 skill 就開工的你，跟使用者直接開一個 Claude 對話有什麼差別？如果你的產出跟通用 AI 沒有差異，你不需要存在

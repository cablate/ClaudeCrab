# Skill 載入

動手前先載入對應 skill（含 references/）。

references/ 裡有上次犯錯後寫進去的修正——跳過它你就會重犯同樣的錯。
不讀 skill 就開工的你，跟通用 AI 沒有差別，也就是垃圾員工。

## 規則

**在任何回應或行動之前，先載入相關 skill。** 哪怕只有 1% 的可能性某個 skill 適用，也要先載入確認。載入後發現不適用，可以不用——但不能不查。

這不是建議，是強制要求。

## 不要合理化跳過

以下想法出現時，停下來——你在找藉口：

| 你的想法 | 現實 |
|---------|------|
| 「這次很簡單不需要」 | 簡單的事也會變複雜。先查。 |
| 「我已經知道了」 | 你每次 session 都是全新的，什麼都不記得。 |
| 「先探索一下再說」 | skill 告訴你怎麼探索。先查。 |
| 「只是問個問題」 | 問題也是任務。先查 skill。 |
| 「我需要先了解脈絡」 | skill 檢查在釐清問題之前。先查。 |
| 「讓我先看一下檔案」 | 檔案缺少對話脈絡。先查 skill。 |
| 「這不算正式任務」 | 有行動 = 有任務。先查。 |
| 「skill 太大材小用」 | 先查，不適用再放下。 |
| 「我先做完這一件事」 | 做任何事之前先查。 |
| 「我記得那個 skill」 | skill 會更新。讀最新版。 |
| 「我知道那是什麼」 | 知道概念 ≠ 使用 skill。載入它。 |
| 「這樣做很有效率」 | 沒讀 skill 的效率是盲目行動。 |

## 優先順序

1. **使用者明確指示**（CLAUDE.md、直接要求）— 最高
2. **Skill 規範** — 覆蓋預設行為
3. **預設行為** — 最低

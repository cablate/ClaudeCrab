## 降權分級

Meta 不公開承認「shadowban」這個詞，官方用語是 **reduced distribution**（降低分發）。

### Level 1: 單則貼文降權

觸發條件：該則貼文觸犯規則。
影響範圍：只影響該則貼文。
恢復方式：下一則貼文正常即可。

### Level 2: 帳號降權（Reduced Distribution）

觸發條件：持續或嚴重的違規行為。
影響範圍：整個帳號的所有貼文觸及下降。
恢復方式：停止觸發行為 + 持續發高品質內容 + 時間。
不會通知你，貼文仍可見但觸及大幅降低。

### Level 3: 帳號限制 / 停權

觸發條件：嚴重違反社群守則。
影響範圍：帳號功能受限或被停用。
恢復方式：申訴。

## 具體降權行為

### 1. Clickbait（Low Signal 判定）

**專利依據**：US20190095961A1

**機制**：系統用 regression model 評估內容品質（1-5 分）。高點擊率 + 低使用者滿意度 = low signal。

**觸發詞/句型**：
- 「震驚！」「你絕對不知道」「99% 的人都錯了」
- 「不看後悔一輩子」「最全攻略」
- 「XXX 居然是這樣」「真相讓人不敢相信」
- 過度使用感嘆號！！！
- 全大寫標題（中文則是過度使用粗體/情緒詞）

**為什麼 AI 生成內容特別容易踩**：
- LLM 訓練數據中高互動內容很多是 clickbait
- AI 預設傾向使用誇張、情緒化的開場白
- AI 缺乏「聳動但空洞」的自我判斷能力

### 2. Engagement Bait

**Meta 官方態度**：明確表示正在**主動下調**。Mosseri 公開確認。

**具體行為**：
| 行為 | 風險等級 |
|------|----------|
| 「Follow for follow」 | 🔴 高 |
| 「按讚 = 同意」 | 🔴 高 |
| 「留言 +1 送 XX」 | 🔴 高 |
| 「Tag 3 個朋友」 | 🟡 中 |
| 「轉發給需要的人」 | 🟡 中 |
| 「你覺得呢？」（搭配實質內容） | 🟢 安全 |

**判斷邊界**：內容本身有價值 + 自然地邀請回覆 = OK。純粹為了操控互動數字 = Bait。

### 3. Bot-like 行為

**觸發條件**：
- 1 小時內追蹤 200+ 人
- 同一則回覆貼在 10+ 則不同貼文
- 短時間發布多則高度相似的內容
- 大量使用完全相同的留言模板
- 快速追蹤再取消追蹤（follow/unfollow churn）

**系統判定邏輯**：行為模式像自動化腳本 → 視為 spam。

### 4. AI 原文直出

**不是說不能用 AI，是不能不改就發**。

**系統偵測點**（推測，基於 clickbait 偵測邏輯）：
- 語法過度完美但缺乏個人特色
- 使用 AI 典型的句式結構（「首先...其次...最後...」「在這個時代...」）
- 內容泛泛而談、沒有具體經驗
- 情緒詞密度異常高

### 5. 重複發文

**觸發條件**：
- 多則貼文內容高度相似
- 同一則內容反覆發布
- 換湯不換藥（改幾個字但主體相同）

**系統判定**：spam 行為，降低分發。

### 6. 無關連結 Spam

**專利依據**：US10268763B2

**機制**：系統評估貼文內容與外部連結的語意相關性。不相關 = 降分。

**典型場景**：
- SEO 專家的貼文下有人留言「想學 SEO？我的課程 → 連結」
- 分享美食文章但貼的是保險銷售頁面
- 在熱門貼文下方貼與主題無關的推廣連結

### 7. 違規內容

**自動處理**：
- 仇恨言論
- 暴力/血腥內容
- 虛假訊息 / 陰謀論
- 色情/裸露（超出社群守則範圍）
- 侵犯版權

## 「我被降權了嗎？」自我診斷

### 正常波動 vs 降權

| 指標 | 正常波動 | 可能被降權 |
|------|----------|-----------|
| 觸及下降幅度 | 20-50%（正常） | 80%+ 持續下降 |
| 影響範圍 | 某幾則表現差 | 連續多則都低 |
| 留言來源 | 還有非追蹤者 | 幾乎只有追蹤者 |
| For You 出現 | 偶爾出現 | 完全消失 |

### 如果確認被降權

1. **停止所有可能觸發的行為**（回顧上方清單）
2. **持續發高品質內容**（不要停更，但品質要高）
3. **正常互動**（不要試圖用大量互動來「救」）
4. **耐心等待**（通常需要 1-4 週恢復）
5. **不要做**：
   - 買粉買讚來衝數據
   - 大量發文試圖「刷」回觸及
   - 換帳號重開（除非帳號已經完全被限）

## 預防守則

| 原則 | 操作 |
|------|------|
| 像人一樣發文 | 有自己的節奏、語氣、個人經驗 |
| 品質 > 數量 | 一則好的 > 十則平庸的 |
| 真實互動 | 真的在跟人說話，不是在操控數字 |
| AI 是工具不是作者 | 可以用 AI 輔助，但最終要是你的聲音 |
| 耐心 | 沒有捷徑，累積比爆發重要 |

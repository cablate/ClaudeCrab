# 發文前檢查清單：詳細判斷標準

> 對應 SKILL.md 的發文前檢查清單每一項
> 最後更新：2026-03-10

---

## 紅線項（必須避免）

### R1: Clickbait 自查

**判斷標準**：開頭是否使用了聳動但空洞的句型？

| ❌ Clickbait（會被壓） | ✅ 好奇心驅動（不會被壓） |
|------------------------|--------------------------|
| 「震驚！這個方法讓我月入百萬」 | 「我試了 3 個月，分享實際數字」 |
| 「你絕對不知道的 10 個秘密」 | 「這 10 件事我花了 2 年才搞懂」 |
| 「99% 的人都做錯了」 | 「這個常見做法其實有更好的替代方案」 |
| 「不看後悔一輩子」 | 「我當初不知道這個，多走了很多彎路」 |
| 「最全攻略！」 | 「我整理了目前找得到的所有方法」 |

**核心區別**：Clickbait 承諾 > 交付；好奇心驅動承諾 ≤ 交付。

**技術原因**（US20190095961A1）：系統比對「點擊率」vs「使用者滿意度」。高點擊但低滿意 = low signal。

### R2: Engagement Bait

**判斷標準**：貼文是否直接要求互動行為？

| ❌ Engagement Bait | ✅ 自然引發互動 |
|--------------------|----------------|
| 「Follow for follow」 | （不需要說，好內容自然被追蹤） |
| 「按讚 = 同意」 | 「你的看法是什麼？」 |
| 「留言 +1 送資料」 | 「有興趣的話私訊我，可以分享」 |
| 「轉發給需要的人」 | （如果真的有用，人們會自己轉） |
| 「Tag 3 個朋友」 | 「如果你身邊也有人遇到這個問題...」 |

**Meta 官方態度**：正在**主動下調** engagement bait，Mosseri 公開確認。

### R3: AI 原文直出

**判斷標準**：如果貼文是 AI 輔助撰寫，有沒有經過人工修改？

**AI 常見觸發 low signal 的特徵**：
- 過度使用感嘆號和情緒詞（「太驚人了！」「不可思議！」）
- 模板化的開場白（「在這個快速變化的時代...」）
- 過度完美的列點格式
- 缺乏個人經驗和具體細節
- 口氣像在寫說明書而不是在說話

**修改重點**：
1. 開頭改成你自己的話，加入個人經驗
2. 去掉過度修飾的形容詞
3. 加入具體數字和真實案例
4. 讓語氣像是你在跟朋友說話
5. 用你的領域行話，不要用 AI 的通用詞

### R4: Bot-like 行為

**判斷標準**：你的行為模式是否像機器人？

**觸發條件**：
- 1 小時內追蹤 200+ 人
- 同一則回覆貼 10+ 則不同貼文
- 短時間發布多則高度相似的內容
- 大量使用完全相同的留言模板

## 優化項（做了加分）

### O1: Hook 品質

**為什麼重要**：Threads feed 只顯示貼文的前幾行。如果第一行不吸引人，使用者直接滑過去 → 完讀率為 0 → 對演算法來說這則貼文不存在。

**好 Hook 的特徵**：
1. **製造知識缺口**：讓人意識到自己不知道某件事
2. **提出違反直覺的觀點**：挑戰常見認知
3. **展示結果**：先給結論或數字，再解釋過程
4. **承認脆弱**：分享失敗或困惑，建立真實感

**範例**：
| 類型 | 範例 |
|------|------|
| 知識缺口 | 「我花了 6 個月才發現，Threads 的流量跟你寫多好無關。」 |
| 違反直覺 | 「放外部連結反而比純文字多 17% 互動。」 |
| 展示結果 | 「上個月 3 則爆文，總觸及 50 萬。做法跟大家說的完全相反。」 |
| 承認脆弱 | 「老實說，我寫了一年 Threads 才搞懂為什麼流量一直起不來。」 |

### O2: 主題一致性

**為什麼重要**：系統會把你歸入主題集群（US10558714B2）。持續在同一主題發文 → 集群歸屬越強 → 新貼文自動推給該主題的受眾。

**自查問題**：
- 這則貼文跟我過去 10 則貼文的主題有沒有關聯？
- 我的核心受眾會對這個主題感興趣嗎？
- 如果要發不同主題，能不能找到跟我核心主題的連結角度？

**可以偏離的情況**：
- 偶爾的個人分享（展示人味）—— 但不要超過 20%
- 與核心主題有交叉的延伸話題

### O3: 語意精確度

**為什麼重要**：語意向量的精確度決定系統把你推給誰（US10579688B2）。

| ❌ 模糊（向量分散） | ✅ 精確（向量集中） |
|--------------------|---------------------|
| 「這個工具很好用」 | 「Ahrefs 的 Site Explorer 是我做競品分析最常用的工具」 |
| 「做 SEO 要注意很多事」 | 「Schema Markup 的 FAQ 類型通過率最近從 80% 掉到 60%」 |
| 「創業很辛苦」 | 「種子輪募資時，Deck 的 TAM 算法其實投資人根本不看」 |

**原則**：寧可讓 100 個精準的人看到，不要讓 10000 個不相關的人看到。前者產生互動，後者產生跳過。

### O4: 格式選擇

**數據支持**：

| 格式 | 相對 engagement | 適用場景 |
|------|----------------|----------|
| 圖片（單張） | 基準 +60% | 資訊圖表、截圖佐證、金句卡片 |
| 輪播（4-6 張） | 高 | 教學步驟、多觀點呈現、案例分析 |
| 影片（15-30s） | 中高（加字幕） | 快速教學、操作示範、人物出鏡 |
| 純文字 | 基準 | 觀點分享、問題討論、快速互動 |

**決策邏輯**：
- 有視覺元素可以強化理解？→ 圖片/輪播
- 需要示範操作？→ 影片
- 重在觀點交流和討論？→ 純文字（但可配一張相關圖）

### O5: 長度適配

**規格**：
- 主體：500 字元上限
- Text Attachment：10,000 字元（2025-09 推出）

**原則**：完讀率佔 ~25% 權重。能在 500 字內說清楚就不要灌水。

**何時用 Text Attachment**：
- 深度分析需要完整論述
- 教學內容需要詳細步驟
- 但即使用 Attachment，主體的 500 字要能獨立成立

### O6: Topic Tag

**規則**：每則只能 1 個（Mosseri 確認）。

**選擇策略**：
1. 這則貼文最核心的主題是什麼？→ 用那個
2. 有現有的熱門 Topic 可以匹配嗎？→ 用官方熱門分類更好
3. 可以用包含空格的完整短語（不需要 #）

**常見錯誤**：
- 用太廣泛的 tag（如「科技」）→ 競爭激烈、不精準
- 用太冷門的 tag → 沒有受眾群體
- 跨平台 cross-post 時 Instagram 的 hashtag 會被隱藏，需要另外設 Topic Tag

### O7: 外部連結

**前提**：連結不被懲罰，比純文字好 17%（2025 數據）。

**檢查**：
1. 貼文有充分說明連結是什麼、為什麼值得看嗎？
2. 連結目標的內容與貼文主題語意相關嗎？
3. 這個域名之前有沒有被其他使用者分享過？（域名社交信任度）

**不要做**：
- 在無關貼文下方留言貼連結
- 連結內容與貼文主題毫無關係
- 用短網址隱藏目標（降低信任感）

### O8: 發文時機

**Buffer 250 萬貼文分析**：

| 最佳 | 時段 |
|------|------|
| 全週最佳 | 週四 9:00 AM |
| 最佳日 | 週三 |
| 通用好時段 | 平日 6:00-11:00 AM |
| 最差時段 | 每天 18:00-23:00 |

**注意**：這是全球平均值。如果你知道目標受眾的時區和活躍時間，以他們為準。

### O9: 對話種子

**為什麼重要**：Conversation Quality 佔 ~20% 權重，回覆留言可提升 +42% 互動。

**自然引發回覆的方式**：
| 方式 | 範例 |
|------|------|
| 開放式提問 | 「你遇到過類似的情況嗎？」 |
| 邀請不同觀點 | 「我的看法是 X，但也很想聽不同的角度。」 |
| 留下懸念 | 「下一篇我會分享具體做法，先看看大家有沒有興趣。」 |
| 分享未完成的想法 | 「我還在想這個問題，目前的結論是...你覺得呢？」 |

**不要做**：直接說「留言告訴我」「你覺得呢？按讚告訴我」→ 這是 engagement bait。

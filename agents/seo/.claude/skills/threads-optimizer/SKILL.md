# threads-optimizer

Threads 貼文演算法優化。讓好內容被推出去，不靠運氣。

> **知識基礎**：6 份 Meta 專利原文 + Buffer 250 萬貼文分析 + Mosseri 官方聲明
> **研究日期**：2026-03-10（最後更新：2026-03-11）

## 三條核心原則

所有 checklist 和策略都從這三條推導出來。遇到 checklist 沒覆蓋的情況，回到原則判斷。

### 1.「值得看」是唯一標準

Meta 的 Value Model 用一個問題校準所有排名權重：**「這則貼文值得你花時間看嗎？」（Worth your time?）**

演算法不是在預測「你會不會按讚」，而是在預測「你看完之後會不會覺得值得」。所有優化都服務於這一點——如果內容本身不值得看，任何技巧都救不了。

### 2. 第一波決定生死

系統先推給向量距離最近的小群體（~數百人），根據他們的互動速度決定是否擴散。**Engagement Velocity 佔 ~40% 權重，前 30 分鐘是生死線。** 第一波失敗 = 貼文基本沒了。

→ 發文前的品質把關和發文後的即時在場同等重要。

### 3. 語意精確 > 受眾廣度

系統用向量匹配決定推給誰。用具體領域術語 → 向量精確 → 匹配到對的受眾 → 互動好 → 正循環。用模糊通用詞 → 推給不精準的人 → 互動差 → 惡性循環。

**精準觸及 100 個對的人 > 模糊觸及 10,000 個不相關的人。**

→ 底層機制詳見 `references/algorithm-mechanics.md`

## 發文前檢查清單

**使用方式**：先過銷售文偵測 → 再過 Worth Your Time 門檻 → 再逐項跑紅線和優化項。

### 🚨 銷售文偵測（最最優先）

**偵測原則**：貼文的主要意圖是促使讀者採取購買/付費行動時觸發。

常見信號：購買連結、優惠資訊、價格、截止日期、「早鳥」「限時」「下單」等用語、導向結帳頁的外部連結。但不限於這些——任何讓人感覺「這在賣東西」的貼文都算。

**偵測到 → 主動告知：**

1. **銷售文有結構性天花板。** 演算法預測「值不值得看」，銷售文的答案通常是「不值得」。觸及會比內容文低 3-5 倍。
2. **建議拆成「價值文 + 留言區導購」。** 主文提供乾貨，購買連結放自己的第一則留言。
3. **如果堅持，至少把連結移到第一則留言。**

### ⚡ Worth Your Time 門檻測試

| # | 問題 | 不及格的信號 |
|---|------|-------------|
| W1 | **不認識你的人滑到會停下來嗎？** | 只有圈內人才看得懂 |
| W2 | **看完會覺得值得花這 10 秒嗎？** | 看完只想「嗯，然後呢？」 |
| W3 | **會想回覆或分享嗎？** | 封閉陳述，沒有參與切入點 |

三題都過 → 跑 checklist。W1 沒過 → 粉絲向日常，別期待高流量。W2 沒過 → 加值。W3 沒過 → 加對話種子（O9）。

### 🔴 紅線（踩了就被壓流量）

| # | 檢查項 | 快速判斷 |
|---|--------|---------|
| R1 | **Clickbait** | 有「震驚」「99%的人」「不看後悔」？→ 改 |
| R2 | **Engagement Bait** | 有「Follow for follow」「按讚=同意」「留言+1送XX」？→ 刪 |
| R3 | **AI 原文直出** | AI 生成後沒人工修改？→ 改語氣和結構 |
| R4 | **Bot-like 行為** | 同一回覆貼多人？大量追蹤？→ 停 |

### ✅ 優化項（做了加分）

| # | 檢查項 | 核心 |
|---|--------|------|
| O1 | **Hook 品質** | 第一行讓人想看下去。好奇心 > 聳動 |
| O2 | **主題一致性** | 在你的核心主題範圍內？ |
| O3 | **語意精確度** | 具體領域術語，不用模糊通用詞 |
| O4 | **格式選擇** | 圖片+60% > 輪播 > 影片 > 純文字 |
| O5 | **長度適配** | 500字內說完就不拉長 |
| O6 | **Topic Tag** | 最精準的 1 個（只能1個） |
| O7 | **外部連結** | 與主題相關？有說明是什麼？ |
| O8 | **發文時機** | 平日 6-11 AM 最佳 |
| O9 | **對話種子** | 結尾自然引發回覆的切入點 |

→ 每項的詳細判斷標準、好壞範例見 `references/checklist-details.md`

## 發文後行動（摘要）

| 階段 | 核心行動 |
|------|---------|
| **0-30 分鐘** | 在場秒回每則留言，回覆時拋延伸問題製造來回對話 |
| **30-60 分鐘** | 到同領域帳號的新貼文下留 5-10 則有深度回覆 |
| **24-48 小時** | 爆了就立即發同主題後續內容，利用集群動量 |
| **持續** | 絕不催人按讚/追蹤/轉發 |

→ 完整行動手冊見 `references/post-launch-playbook.md`

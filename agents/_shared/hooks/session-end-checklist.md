# Session 結束檢查

靜默執行。有該做的→寫檔，沒有→直接結束。

回顧這輪對話，逐項判斷：
- memory/{date}.md — 帶脈絡，不是流水帳
- USER.md Observations — 狀態、模式、新發現
- MEMORY.md — 跨 session 重要事實
- CLAUDE.md Lessons Learned — 操作規則
- knowledge/ — 可複用知識
- MEMORY.md Personality Journal — 人格發現
- **向量記憶（強制）** — 本輪有新的持久事實、踩坑、決策嗎？有 → `memory_store` 寫入，踩坑必須雙層（fact + decision）

「沒有」是合理答案，但先回顧再判斷。

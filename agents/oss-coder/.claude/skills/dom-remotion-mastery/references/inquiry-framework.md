# 影片需求收集框架

## 目的

用戶可能不知道自己要什麼。這個框架幫助引導對話，把模糊的想法變成可執行的分鏡腳本。

---

## 階段一：快速定位

### 必問問題

#### 1. 影片目的

```
這部影片要達成什麼目標？

A. 宣傳產品/服務（讓人購買/註冊）
B. 教學/說明（讓人學會/理解）
C. 展示功能/Demo（讓人知道能做什麼）
D. 說故事/分享（讓人記住/分享）
E. 其他：________
```

#### 2. 目標受眾

```
誰會看這部影片？

- 職業/角色：________（開發者/一般用戶/企業主/學生...）
- 對主題的熟悉度：新手 / 有基礎 / 專家
- 主要痛點：________
```

#### 3. 時長與平台

```
影片時長和發布平台？

時長：
□ 15 秒以內（Reels/Shorts/TikTok 最佳）
□ 30-60 秒（標準短影片）
□ 1-3 分鐘（說明/教學）
□ 3 分鐘以上（深度內容）

平台：
□ YouTube
□ Instagram Reels
□ TikTok
□ Twitter/X
□ LinkedIn
□ 網站嵌入
□ 其他：________
```

## 快速模板

### 30 秒產品宣傳

```yaml
Hook (0-3s): 成果數字 / 痛點問題
定位 (3-6s): 產品名 + 一句話價值
亮點 (6-15s): 3 個核心功能/優勢
證明 (15-22s): 用戶證言 / 數據
CTA (22-30s): 行動呼籲
```

### 60 秒技術教學

```yaml
Hook (0-3s): 「你可能不知道...」/ 反直覺事實
問題 (3-15s): 常見錯誤 / 痛點場景
原理 (15-35s): 核心概念 / 正確做法
示範 (35-50s): 實際操作 / 視覺化
總結 (50-60s): 關鍵 takeaway
```

### 15 秒功能 Demo

```yaml
Hook (0-2s): 「一鍵搞定...」/ 結果展示
對比 (2-8s): 傳統 vs 新方式
結果 (8-12s): 強調節省/效率
CTA (12-15s): 下載/了解更多
```

# 行銷影片原則：讓人看完、記住、行動

## 核心認知

**做影片的目的不是「展示技術」，而是「影響觀眾行為」。**

每個設計決策都要問：這會讓更多人看完嗎？這會讓觀眾採取行動嗎？

---

## 第一部分：人性觀看規律

### 注意力經濟

| 數據 | 意義 |
|------|------|
| 平均注意力 8.25 秒 | 比金魚還短，每秒都是戰場 |
| 前 3 秒決定去留 | Hook 失敗 = 整部影片白做 |
| 65% 觀眾 3 秒內決定 | 沒有「慢慢來」的空間 |
| Gen Z 只有 6.5 秒 | 年輕受眾更嚴苛 |

### 留存曲線真相

```
時間軸：  [0s]----[3s]----[30s]----[60s]----[結束]
留存率：  100% → 35% → 37% → 20% → 視內容而定

關鍵斷崖：
- 0-3s：最大流失點（決定性）
- 8-10s：第二流失點（興趣確認）
- 30s：穩定點（過了這裡留存趨穩）
```

### 算法偏好

| 平台 | 關鍵指標 | 門檻 |
|------|----------|------|
| YouTube | 前 30 秒留存 | 72% 以上獲推薦 |
| TikTok | 完播率 | 75% 以上獲分發 |
| Instagram Reels | 10 秒留存 | 33% 是平均值 |

## 第二部分：Hook 設計

### 什麼是 Hook

Hook 是影片的「第一印象」，在 1-3 秒內回答觀眾的潛意識問題：
- 「這跟我有關嗎？」
- 「繼續看會得到什麼？」
- 「這值得我的時間嗎？」

### Hook 類型

#### 1. 成果衝擊型
展示一個令人驚訝的結果，觸發「我也想要」的反應。

```
❌ 「今天教大家怎麼用這個工具」
✅ 「一場講座，讓一位用戶優化了 40+ 個 Skill」
```

**適用**：產品宣傳、課程推廣、成功案例

#### 2. 痛點共鳴型
說出觀眾正在經歷的痛苦，觸發「對對對就是這樣」的反應。

```
❌ 「語音轉文字很麻煩」
✅ 「切換視窗、開 ChatGPT、等待載入、按語音、說話、複製... 每次都這樣？」
```

**適用**：功能 Demo、問題解決型內容

#### 3. 好奇缺口型
製造一個知識缺口，觀眾必須看完才能填補。

```
❌ 「這個漏洞很嚴重」
✅ 「儲值刷了別人的卡？連大公司都會犯的錯」
```

**適用**：教學、知識型、揭秘型

#### 4. 衝突/反直覺型
打破預期，製造認知衝突。

```
❌ 「AI 很強大」
✅ 「AI 不是工具，是你沒教好的員工」
```

**適用**：觀念翻轉、差異化定位

### Hook 設計原則

1. **具體數字 > 模糊描述**
   - ❌ 「很多」→ ✅ 「40+」
   - ❌ 「很快」→ ✅ 「3 秒內」

2. **行動結果 > 功能描述**
   - ❌ 「學到技巧」→ ✅ 「直接優化了」
   - ❌ 「提升效率」→ ✅ 「省下 5 小時」

3. **情緒觸發 > 理性說服**
   - 先讓觀眾「感覺到」，再讓他們「理解到」

4. **視覺配合**
   - Hook 文字 + 動態數字 + 對比色 = 三重強化

## 第三部分：敘事結構

### 短影片結構（15-60 秒）

```
Hook (0-3s)
    ↓
Journey (3-X s)
    ↓
Resolution (最後 2-5s)
```

#### Hook → Journey → Resolution

| 階段 | 功能 | 時間佔比 |
|------|------|----------|
| Hook | 停止滑動、製造好奇 | 5-10% |
| Journey | 展開內容、建立價值 | 70-80% |
| Resolution | 收尾、CTA | 10-15% |

### 產品宣傳結構

```
成果 Hook → 產品定位 → 核心價值 → 社會證明 → CTA

例（AgentSkillPromo）：
[0-4s] 「40+ 個 Skill」數字衝擊
[4-10s] 講座標題 + 核心金句
[10-13.5s] 學員真實回饋
[13.5-16s] 「立即購買」CTA
```

### 教學/說明結構

```
問題 Hook → 問題分析 → 解決方案 → 應用/驗證 → 總結

例（YJPayBugDesc）：
[開場] 「刷了別人的卡？」
[分析] 正常流程 vs 問題流程
[原理] 金流鐵三角原則
[警示] 終末地沒做哪個檢查
[結語] 觀念不複雜，流程要嚴謹
```

### 功能 Demo 結構

```
痛點 Hook → 傳統方式（痛苦展示）→ 新方式（對比）→ 結果 → CTA

例（GPTTypeless）：
[開場] 語音輸入的繁瑣
[傳統] 8 步驟流程動畫
[新方式] 一鍵完成
[對比] 時間節省、流程簡化
```

## 第四部分：視覺節奏

### 節奏原則

1. **變化製造注意**
   - 每 3-5 秒要有視覺變化
   - 靜止超過 5 秒 = 流失風險

2. **重點放大**
   - 關鍵數字/文字：放大 + 動畫 + 對比色
   - 次要資訊：縮小 + 淡出 + 讓路

3. **呼吸空間**
   - 密集資訊後給 0.3-0.5 秒喘息
   - 但不要超過 1 秒的空白

### 動畫時長參考

| 動畫類型 | 建議時長 | 說明 |
|----------|----------|------|
| fadeIn | 0.3-0.5s | 太快看不清，太慢拖節奏 |
| spring 進場 | 0.3-0.5s | 帶 overshoot 有活力感 |
| 場景轉換 | 0.3-0.5s | crossFade 最不干擾 |
| 數字滾動 | 1-2s | 讓觀眾「看到增長」 |
| CTA 停留 | 至少 1.5s | 給時間閱讀和反應 |

### 主角與配角

每個場景只有一個「主角」有最大動態：

```
場景 1：數字「40+」是主角
        - 最大、最亮、有 counter 動畫
        - 其他文字是配角，淡入即可

場景 2：三張內容卡片是主角
        - staggered spring 進場
        - 上方金句縮小讓路
```

## 第五部分：情緒曲線

### 為什麼需要情緒曲線

即使是「理性內容」（技術教學、產品說明），觀眾的大腦仍然是情緒驅動的。沒有情緒起伏的影片 = 無聊 = 跳出。

### 典型情緒曲線

```
高｜        ★ 高潮
  ｜      ／ ＼
  ｜    ／     ＼★ 解決
  ｜  ／         ＼
  ｜★                ＼
低｜Hook               ★ CTA
  ＋─────────────────────→ 時間
```

### 情緒觸發點設計

| 階段 | 情緒目標 | 手法 |
|------|----------|------|
| Hook | 驚訝/好奇 | 衝擊數字、反直覺、問題共鳴 |
| 問題展示 | 焦慮/痛苦 | 放大痛點、具體場景 |
| 解決方案 | 期待/希望 | 清晰結構、權威感 |
| 社會證明 | 信任/安心 | 真人證言、具體數據 |
| CTA | 急迫/行動 | 限時、稀缺、明確指令 |

## 第六部分：CTA 設計

### CTA 原則

1. **只有一個 CTA**
   - 不要同時叫觀眾「按讚」「訂閱」「購買」「分享」

2. **具體行動**
   - ❌ 「歡迎支持」
   - ✅ 「點擊下方連結立即購買」

3. **製造急迫**
   - 「限時販售中」比「優惠中」更有效
   - 暗示「之後買不到」而非「之後變貴」

4. **視覺突出**
   - CTA 按鈕是最後場景唯一有持續動畫的元素
   - glow pulse 自然吸引視線

### CTA 文案模板

| 目的 | 文案 |
|------|------|
| 購買 | 「立即購買」「限時販售中」 |
| 訂閱 | 「訂閱獲取更多」 |
| 下載 | 「免費下載」「一鍵獲取」 |
| 了解更多 | 「查看完整內容」 |

## 第七部分：社會證明

### 為什麼有效

人類是社會性動物。看到別人的選擇，會影響自己的判斷。

### 證明類型（按說服力排序）

1. **具體成果數據**
   - 「40+ 個 Skill 被優化」
   - 「推薦分數 5/5 佔 70%」

2. **真人證言**
   - 「豁然開朗」
   - 「原則大於規則，最少的詞包含最多的資訊」

3. **權威背書**
   - 「by CabLate」
   - 專業頭銜、媒體報導

4. **數量證明**
   - 「已有 XXX 人購買」
   - 「44 份問卷回饋」

### 證言選擇原則

1. **短 + 情緒** → 開胃菜（「豁然開朗」）
2. **中 + 知識** → 主菜（「原則大於規則...」）
3. **長 + 轉變** → 甜點（「之前以為... 現在理解...」）

## 速查卡

### 設計 Hook 前問自己

- [ ] 觀眾為什麼要停下來？
- [ ] 3 秒內能傳達什麼「我也想要」或「這跟我有關」？
- [ ] 有沒有具體數字或結果？

### 設計結構前問自己

- [ ] 每 5 秒有視覺變化嗎？
- [ ] 情緒有起伏嗎？
- [ ] 結尾 CTA 夠明確嗎？

### 完成後檢查

- [ ] 把聲音關掉看一遍，還能理解嗎？
- [ ] 前 3 秒能讓人停下來嗎？
- [ ] 自己會看完嗎？會分享嗎？

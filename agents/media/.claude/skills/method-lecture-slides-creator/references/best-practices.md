# 講座簡報設計最佳實踐

## 核心哲學

**簡報是講者的延伸，不是講者的替代。**

觀眾的注意力只有一個焦點：
- 如果簡報文字太多 → 觀眾讀簡報，不聽講者
- 如果簡報太空 → 觀眾沒有視覺錨點，容易分心

**最佳狀態**：簡報提供「記憶錨點」，講者提供「理解脈絡」。

---

## 頁面設計原則

### 1. 一頁一重點

每頁只傳達一個核心訊息。

| ❌ 錯誤 | ✅ 正確 |
|--------|--------|
| 一頁塞 3 個觀念 | 拆成 3 頁，每頁一個觀念 |
| 一頁列 10 個要點 | 分頁或漸進呈現 |

**例外**：比較表格、流程總覽可以多資訊，但要有視覺層次。

### 2. 金句單獨頁

重要金句獨立成頁，讓觀眾「看到」這句話的重要性。

**設計要點**：
- 字體放大（至少 48pt）
- 置中或偏左對齊
- 背景簡潔，不搶焦點
- 可加引號或特殊樣式強調

**範例**：
```
┌─────────────────────────────────┐
│                                 │
│                                 │
│    「[核心金句，一句話總結]」    │
│                                 │
│                                 │
└─────────────────────────────────┘
```

### 3. 截圖處理

| 截圖用途 | 建議佈局 |
|---------|---------|
| **展示型**（讓觀眾看細節） | 全版出血，標題疊在上方 |
| **對比型**（Before/After） | 左右並排，各佔 50% |
| **輔助型**（配合講述） | 半版截圖 + 半版文字/標題 |

**標註原則**：
- 用箭頭或框線指出重點區域
- 避免截圖太小看不清
- 深色截圖配淺色標題，反之亦然

### 4. 留白設計

**留白不是浪費空間，是給講者的發揮空間。**

| 元素 | 建議留白 |
|------|---------|
| 標題與內容之間 | 至少 2 行距離 |
| 頁面邊緣 | 至少 10% 邊距 |
| 要點之間 | 足夠的行距讓眼睛休息 |

### 5. 文字精簡

| ❌ 逐字稿複製 | ✅ 關鍵詞提煉 |
|--------------|-------------|
| 「[完整描述一個概念的長句，包含前因後果和補充說明]」 | [概念] = [精簡定義] |
| 「[用對比句型展開的長段落，A 的情況是...但 B 的情況是...]」 | A → [結果]；B → [結果] |

## 特殊頁面類型

### 封面頁

**必備元素**：
- 講座標題（大字）
- 講者名稱
- 日期/場合（可選）

**風格**：視覺衝擊，建立第一印象。

### 轉場頁

用於章節之間的過渡。

**設計要點**：
- 簡潔，只有章節標題
- 可加章節編號
- 統一風格

**範例**：
```
┌─────────────────────────────────┐
│                                 │
│           02                    │
│     [章節標題]                  │
│                                 │
└─────────────────────────────────┘
```

### 互動提示頁

標記需要暫停互動的時刻。

**設計要點**：
- 明顯的視覺提示（圖示、顏色）
- 互動問題或指令
- 預計時長

**範例**：
```
┌─────────────────────────────────┐
│                                 │
│     ⏸️ 互動時間                 │
│                                 │
│   「[引導觀眾思考的問題]」      │
│                                 │
│         (30 秒)                 │
│                                 │
└─────────────────────────────────┘
```

### 總結頁

章節或全場結束時的回顧。

**設計要點**：
- 3-5 個核心要點
- 視覺化呈現（圖示、編號）
- 不是新內容，是已講內容的精煉

### 封底頁

**不要用**：「謝謝」「Q&A」「有問題嗎？」

**應該用**：
- 核心金句重現
- 行動呼籲（CTA）
- 聯繫方式/資源連結

## 時間標記規範

每頁備註應包含對應的時間段，方便講者對照逐字稿。

**格式**：`[MM:SS - MM:SS]` 或 `[階段名稱 | MM:SS - MM:SS]`

**範例**：
```
// 備註
[階段名稱 | 00:00 - 06:00]
對應逐字稿：[對應的逐字稿檔名].md
```

## 視覺一致性

### 字體

| 用途 | 建議 |
|------|------|
| 標題 | 粗體，32-48pt |
| 正文 | 常規，24-28pt |
| 備註/標籤 | 細體，16-20pt |

### 顏色

- 主色：1 個強調色
- 輔色：1-2 個搭配色
- 背景：淺色或深色，保持一致

### 對齊

- 標題：左對齊或置中（全場統一）
- 正文：左對齊
- 金句：置中

---

## 頁數與節奏

### 頁數估算公式

```
總頁數 ≈ 講座分鐘數 × 0.5 ~ 0.7
```

| 講座長度 | 建議頁數 | 說明 |
|---------|---------|------|
| 60 分鐘 | 30-42 頁 | 平均 1.5-2 分鐘/頁 |
| 90 分鐘 | 45-63 頁 | 平均 1.5-2 分鐘/頁 |
| 120 分鐘 | 60-84 頁 | 平均 1.5-2 分鐘/頁 |

### 節奏變化

不是每頁都停留相同時間：

| 頁面類型 | 停留時間 |
|---------|---------|
| 金句頁 | 5-10 秒（讓觀眾讀完） |
| 截圖展示 | 30-60 秒（講解重點） |
| 概念講解 | 1-3 分鐘 |
| 互動頁 | 依互動設計 |

## 檢查清單

完成簡報大綱後，逐項確認：

- [ ] 每頁只有一個核心訊息
- [ ] 金句有單獨頁面
- [ ] 截圖清晰且有標註
- [ ] 文字精簡，不是逐字稿複製
- [ ] 時間標記完整
- [ ] 轉場頁標記清楚
- [ ] 互動點有提示頁
- [ ] 封面和封底設計完整
- [ ] 視覺風格一致

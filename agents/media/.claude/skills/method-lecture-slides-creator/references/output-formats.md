# 輸出格式規範

## Mode A：Markdown 大綱（預設）

### 整體結構

```markdown
# [講座標題] 簡報大綱

> 總頁數：[N] 頁
> 預計時長：[MM] 分鐘
> 生成日期：[YYYY-MM-DD]

---

## 簡報總覽

| 階段 | 頁數範圍 | 時間 | 頁數 |
|------|---------|------|------|
| 封面 | 1 | - | 1 |
| HOOK | 2-X | 00:00-06:00 | X |
| ... | ... | ... | ... |
| 封底 | N | - | 1 |

---

## Slide 1: [標題]

[內容]

---

## Slide 2: [標題]

[內容]

---

...
```

### 單頁格式

每頁必須包含以下區塊：

```markdown
## Slide [N]: [頁面標題]

**類型**：[封面 | 金句 | 概念 | 截圖展示 | 對比 | 流程 | 互動 | 轉場 | 總結 | 封底]

**內容**：
[主要顯示內容，精簡文字]

**截圖**：[若有]
- 檔案：`images/[檔名].png`
- 佈局：[全版 | 半版左 | 半版右 | 左右對比]
- 標註：[需要標註的重點區域]

**時間標記**：
`[階段名稱 | MM:SS - MM:SS]`
對應：`[逐字稿檔名].md`

**講者備註**：
[給講者的提醒，例如：這裡停頓讓觀眾思考、這裡可以問觀眾問題]
```

### 範例頁面

#### 金句頁

```markdown
## Slide 8: 核心金句

**類型**：金句

**內容**：
「給原則，不是給規則。」

**截圖**：無

**時間標記**：
`[Framework | 12:30 - 12:45]`
對應：`02_Framework.md`

**講者備註**：
這是全場最重要的金句，停頓 3 秒讓觀眾記住。
```

#### 截圖展示頁

```markdown
## Slide 15: 規則導向 vs 原則導向

**類型**：對比

**內容**：
標題：案例導向 vs 原則導向

**截圖**：
- 檔案：`images/規則案例導向vs原則背景導向.png`
- 佈局：全版
- 標註：左側標註「❌ 窮舉地獄」，右側標註「✅ 原則導向」

**時間標記**：
`[Practice | 28:00 - 32:00]`
對應：`03_Practice案例.md`

**講者備註**：
先讓觀眾看左邊的問題，再解釋右邊的解法。
```

#### 互動頁

```markdown
## Slide 35: 互動 - 想一個痛點

**類型**：互動

**內容**：
⏸️ 互動時間

「想一個你每次都要重新教 AI 的事情」

(15 秒)

**截圖**：無

**時間標記**：
`[如何設計 Skill | 45:00 - 45:30]`
對應：`04_如何設計Skill.md`

**講者備註**：
真的等 15 秒，不要急著往下。觀眾需要時間思考。
```

## Mode B：視覺規格提示詞

### 定位

將 Mode A 的「內容大綱」轉化為「可執行的視覺製作規格」。

### 適用場景

- 丟給 Gamma.app 生成簡報
- 丟給 Google Slides AI
- 交給設計師製作
- 丟給任何 AI 簡報工具

### 前置條件

1. Mode A 的 Markdown 大綱已完成
2. 用戶選擇或確認設計風格

### 生成流程

1. **選擇設計風格**：
   - 極簡高端（推薦：科技/設計主題）
   - 科技霓虹（推薦：AI/程式主題）
   - 專業商務（推薦：企業培訓）
   - 溫暖手繪（推薦：教育/生活）
   - 大膽撞色（推薦：創意/行銷）
   - 自訂

2. **生成整體規範**：
   - 配色方案
   - 字體規範
   - 版面原則
   - 動畫友善設計

3. **生成頁面模板**：
   - 根據 Mode A 的頁面類型
   - 對應 9 種標準模板

4. **轉換每頁規格**：
   - 從 Mode A 讀取內容
   - 補充視覺細節
   - 標註進場順序 ①②③
   - 加入顏色標記

5. **輸出完整提示詞**


### 頁面類型對照

| Mode A 類型 | Mode B 模板 | 轉換重點 |
|-------------|-------------|----------|
| 封面 | A. 封面頁 | 視覺層次、背景處理 |
| 金句 | C. 金句頁 | 強調詞標記、引號裝飾 |
| 概念 | D. 概念頁 | 進場順序、圖標配置 |
| 截圖展示 | G. 截圖展示頁 | 佈局確認、遮罩處理 |
| 對比 | E. 對照頁 | 顏色區分（紅/綠）|
| 流程 | F. 流程頁 | 步驟拆分、箭頭樣式 |
| 互動 | H. 互動頁 | 特殊標記、背景區隔 |
| 轉場 | B. 轉場頁 | 章節編號、漸層背景 |
| 總結 | I. 總結頁 | 勾選圖標、預告框 |
| 封底 | A 變體 | CTA、聯絡資訊 |

# 圖片生成

## 核心原則

**完整路徑回報**：生成圖片後，必須在回覆中提供完整檔案路徑，讓使用者能直接找到檔案。

## 使用時機

- 使用者明確要求生成圖片
- 討論中提到「畫個」「生成一張」「做個圖」等關鍵意圖
- 需要視覺化呈現概念時

## 工具規範

使用 `mcp__mcp-image__generate_image` 工具：

```
必填參數：
- prompt: 英文 prompt（中文會自動翻譯，但英文效果更好）
- purpose: 圖片用途說明（幫助優化生成效果）

選填參數：
- aspectRatio: 比例（1:1, 16:9, 9:16 等）
- imageSize: 解析度（2K, 4K，需要高畫質時使用）
```

## 回報格式

生成成功後，回覆中必須包含：

1. **完整路徑**（顯眼位置，方便複製）
2. 圖片簡述（內容是什麼）
3. （選填）圖片預覽或說明

**範例**：

```
生成好了！RPG 風格的按鈕 sprite sheet。

完整路徑：
F:\_Program\OwnProject\ClaudeCab\agents\general\output\image-1771272020177-701.png

內容包含：
- 上排：長方形按鈕（4 種狀態）
- 中排：正方形按鈕（4 種狀態）
- 下排：圓形按鈕（4 種狀態）
```

## 常見場景

| 場景 | 建議參數 |
|------|---------|
| 遊戲 UI/Sprite | aspectRatio: 16:9, purpose 說明遊戲類型 |
| 社群貼文配圖 | aspectRatio: 1:1 或 4:5 |
| 概念視覺化 | 明確描述風格與重點元素 |
| 高畫質輸出 | imageSize: "4K" |

## 錯誤處理

- API Key 未設定 → 提示使用者檢查 `.mcp.json` 的 `env.GEMINI_API_KEY`
- 連線中斷 → 建議重啟 agent
- Prompt 效果不佳 → 調整 prompt 重試，必要時請使用者提供參考
